# 图片优先画布 · 独立交互原型

本原型用于核对已确认的“图片优先画布与按需参数交互优化方案”。用户已选定单一方案，当前不提供 A/B/C 布局方向，也不加载正式应用脚本。

## 启动

在当前工作副本根目录运行：

```powershell
python -m http.server 18770 --bind 127.0.0.1
```

打开：<http://127.0.0.1:18770/prototype-image-first-canvas.html>

## 范围

- 所有操作都是原型的内存模拟；不连接真实模型、不读取 API key、不调用正式后端，也不使用正式工作流或媒体存储。
- 选择本地图片只用于本次原型内存预览，不上传。
- 刷新页面重置演示状态。默认不持久化；保存按钮可导出原型 JSON 工作流，再导入用于演示。
- 用于评估图片卡片、节点下方参数、放大浮窗、Agent 重叠置顶、参考图顺序、批次浏览及运行反馈；不能把模拟结果视为正式功能已实施。
- 本原型的代码与现有正式代码分开，不能直接提升为正式实现。

## 示例媒体

`assets/scene-snow.png`、`scene-platform.png`、`scene-detail.png`、`product.png` 逐字节复制自本机现有示例媒体，仅用于本地设计评审，没有编辑、缩放、裁切或上传。复制时已比对 SHA-256。

`assets/palette.svg` 为本原型原创色彩参考板，不修改上述图片。

## 已确认的关键约束

- 普通参数面板始终在节点下方，空间不足时由用户手动平移，不自动改变视口或翻转方向。
- 参数面板不随画布缩放；主动放大才切到可拖动的大浮窗，退出后回到节点下方。
- 端口与名称始终完整显示。图片批次浏览不缩减真实批次。
- 参数与 Agent 可重叠，点击可见面板可置顶，并提供找回被完全遮挡面板的入口。
- 修改设置不自动生成，新增“设置已修改，待生成”提醒；普通保存与生成分别操作。

## 第二轮评审调整

- 去掉提示词标题行，助手优化按钮内嵌在输入框右下角，正文预留空间。
- 节点取消占位标题栏，只在选中时将标题浮在节点上方；端口和连线不因选择改变位置。
- 参数面板去掉重复目标标题，保留精简放大/关闭工具和放大模式拖动把手。
- 参考来源改为紧凑多列卡片：普通 480px 面板可容纳三列单图来源；多图来源按组跨列，保留完整图片及连续编号。
- 排序、定位、停用、断开、原图预览和撤销继续可用。图标按钮提供完整名称与说明。


## 第三轮评审：通用输入

- 生图节点左侧只显示一个“输入”，所有旧连接保持原有逻辑用途，并汇入同一端口。
- 图片→参考图，文本→提示词，视角节点→视角提示词，参数→自定义参数。参考/遮罩及文本用途可在输入明细切换；遮罩不凭图片外观猜测。
- 输入明细支持来源查看、用途修改、断开、撤销与参考图管理。重复、循环、容量和运行锁继续校验，同类单输入冲突会提示并保留旧来源。
- “通用输入识别”情景提供文本与 JSON 参数来源；可从输入/输出拖线到空白新建并自动连接，也可直接接线。来源声明的输出类型用于识别，不读取图片语义。
- 上游提示词连接时显示实际输入，本地草稿保留。助手优化明确编辑上游文本；方案应用前检查全部输入用途、内容和参考顺序。
- 输入预览展示有效提示词、视角、参考批次、遮罩和参数合并；模拟生成使用该输入清单。原型没有真实模型请求。
- 浏览器验证：用途切换/撤销、正反向拖线新建/一步撤销、直接文本连接、单用途冲突保护、上游提示词助手应用/撤销、生成时输入锁与连接保留。源码通过 node --check；正式代码未改。


## 第四轮评审：其他图片节点统一输入

- 预览、对比、多图合一、缩放、颜色、保存及视角控制都使用一个通用输入口；导入节点原本没有输入，继续保留为来源。
- 真实用途仍独立：对比按空闲 A/B 分配并可交换；合并按来源顺序展开完整批次；保存自动区分图片/视频，分别保留对应输出；其余图片处理节点只接收图片。生图规则不变。
- 明细支持合法用途调整、指定来源替换、断开及撤销；合并另有前后排序。自动接线遇满位、重复、不兼容、循环或运行锁时保留旧线。
- 正反向拖线新建、直接接线均沿用类型识别。多输出来源按所选输出连线，反向新建选择可接入的输出。新节点不自动填入虚构图片结果。
- 模拟输入会反映到处理预览/完整批次；无有效输入时保留已有结果，并提示缺少输入。所有运算、视频样例与模型交互仍是独立内存模拟，不代表正式实现。
- 下方参数与专用操作仍保留；画布仅由用户手动平移/缩放，焦点操作不会导致容器自行滚动。
- 演示工具新增“图片节点通用输入”情景，覆盖多路来源、A/B、合并批次、视角文本输出、保存图片/视频输入与输出。
