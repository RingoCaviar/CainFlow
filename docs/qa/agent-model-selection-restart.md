# Agent 模型选择重启恢复（prompt-agent#053）

对话模型是全局偏好，沿用既有语义；生图、专用搜索、供应商、思考及尺寸设置仍属于工作流。

## 原因和修复

对话模型原先直接使用浏览器 localStorage，而桌面启动可能使用新的随机端口。跨来源无法读取该值。改用已完成启动恢复的 diskStorage，与全局宽度使用同一持久化服务。存储失败沿用提示、待保存队列及重试。

磁盘无记录时可读取并迁移当前浏览器来源的旧值；磁盘已存在（含明确空值）时不覆盖。不可读取的历史来源无法恢复，不从模型列表或供应商推断原选择。

## 验证

- 浏览器选择第二个对话模型及生图模型，等待磁盘保存，清除浏览器模型键并重建应用。修复前得到 first，修复后仍为 second，生图选择保持。
- 迁移旧值、磁盘优先、浏览器存储拒绝、保存失败、重试、新存储实例恢复。
- 生图、搜索模式与专用模型、三类供应商、两类思考设置及尺寸：序列化恢复、压缩、清空保留、切换工作流隔离。
- 全局面板宽度已有独立磁盘恢复及失败重试回归，一并重跑。

全部使用隔离数据，不调用模型接口。
