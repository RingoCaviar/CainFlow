# Agent 模型供应商显示

## 显示规则

对话、生图、专用搜索和方案步骤菜单显示“模型名 · 供应商”，每个模型提供优先级项及各绑定供应商项；不再用供应商总数量替代选择。无名称时保留 modelId/id 回退，失效供应商保留选择并显示不可用提示。节点原有菜单不变。

原生 select 仍保存模型 ID，自定义菜单另行维护供应商身份；一次选择派发一次事件。触发器悬停提示、步骤继承项和折叠摘要显示完整供应商；刷新签名包含显示标签，使供应商改名后同步更新。不显示密钥和接口地址。详细规则见 [供应商选择与统计](../agent-provider-selection-statistics.md)。
