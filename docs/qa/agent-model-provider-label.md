# Agent 模型供应商显示

## 显示规则

对话、生图、专用搜索和方案步骤模型复用公共 `getModelOptionLabel`，显示“模型名 - 供应商”。多供应商显示配置顺序中的首个供应商及总数量，与节点选择器一致。无名称时保留 modelId/id 回退；无可解析供应商时不猜测渠道。

原生 select 及自定义菜单共用标签，触发器悬停提示包含完整文字。步骤继承项和折叠摘要同样显示供应商；刷新签名包含显示标签，使供应商改名后同步更新。仅改变展示，不修改选中值、事件、保存或 Provider 优先级，不显示密钥和接口地址。
