## 行为与回归

- 候选图片不等于本轮输入：独立生成只接受本轮附件或带用户原话证据的历史素材；明确无参考图时不导入、不连接。直接多步骤方案同样校验导入及外部输入，不能绕过单图规则。
- 仅修改提示词使用上一版实际素材；没有上一版素材时不从候选中补入。最新成品续改、明确旧图、多图澄清沿用原回归。
- 独立生成修改已有目标时，旧参考输入列入断开清单；不能在请求中悄悄保留。聊天回复不创建导入节点。旧方案在完整应用中升级为批量画布方案，结果记录不删除。
- 布局测试覆盖缩放、负坐标、不同高度的远处节点、邻近遮挡、禁用旧保存节点、不同运行模式与图片/视频入口。只更改新节点的位置。
- 正文使用 DOM 文本节点及固定语义标签，支持段落、列表、强调、代码和登记引用；原始存档、用户消息和提示词不改写。只修复可识别的正文换行模式，歧义 `/n` 保留。URL、路径、代码和 HTML 字面量均有回归。
- 七主题 300px 浏览器回归验证模型常驻、正文、折叠详情、纯文字标识、输入与操作分行、隐藏按钮实际不可见及点击命中；现有菜单、参考图、预览、撤销、持久化及异步隔离测试继续运行。
