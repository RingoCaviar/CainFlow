### 图片导入与参考图来源（prompt-agent#026）

- 在 Agent 面板粘贴混合文字与多张图片、拖入文件、上传图片或拖入历史卡片，每张图片建一个 ImageImport 并按输入顺序引用。面板消费事件，不能再由全局导入重复建节点；拖入已选历史项不取消选择。
- 加号面板包含场景／历史页签、搜索、刷新、上传、已选缩略图及清空选择。历史按时间倒序，每批 60 项；列举只读取元数据和懒加载缩略图，勾选或明确点击预览才读取原图。
- 预览按钮独立于选择按钮，使用共享全屏预览；不建节点。切换页签、搜索及关闭浮层保留选择顺序。已选项和发送消息的编号必须一致。
- 历史原图缺失显示错误；保存失败保留单项重试入口并禁止发送未就绪引用。重试使用同一节点；历史项重新勾选复用未修改的自动导入节点，节点图像改变或删除后重新导入。
- 移除引用只移除本次选择，保留已建节点。读取期间移除、清空或切换工作流，完成后不得再创建节点或恢复引用；新工作流不等待旧队列完成。
- 已发送引用继续沿用独立保存的对话图像，删除节点或历史条目后恢复会话仍能查看。自动节点的历史 ID 与原资产标识随节点序列化，支持保存、重建和既有撤销生命周期。

## 显式生图模型选择验收

生图模型选择独立于对话模型，并保存在当前工作流 Agent 数据的可选 `imageModelId` 字段中；存储版本保持 1。旧数据缺少该字段或字段不是字符串时按未选择恢复，不从目标节点、模型顺序或全局偏好推断。仅保存模型选择而没有聊天、方案、参考图或摘要时，不计为 Agent 缓存会话。

| 场景与操作 | 通过条件 |
| --- | --- |
| 新建工作流，设置中只有一个生图模型 | 选择器仍为空，提示选择；聊天和方案预览可用，应用和生成不可执行。 |
| 模型配置延迟加载、排序变化或增加新模型 | 不产生隐式选择，也不改变已有明确选择。 |
| 分别在工作流 A、B 选择不同模型并保存、切换、重新打开 | 各自恢复自己的选择；新工作流和缺少该字段的旧工作流保持为空。 |
| 执行 `/clear` 或 `/compact` | 聊天内容按命令处理，当前生图模型选择保持。 |
| 已有绑定节点时在面板改选另一模型 | 改选本身不修改节点；下一次应用或生成在原节点使用新选择，保持目标绑定。 |
| 已选模型被删除、协议失效或 Provider 不再可用 | 保留草稿并提示重新选择或配置，不回退到其他模型、不发生成请求。 |
| 新选择与方案参数不兼容 | 重新校验并明确拒绝生成，保留草稿供调整，不丢弃参数后悄悄执行。 |
| 目标正在生成时改选模型，或通过另一方案操作同一目标 | 在途节点配置保持稳定，另一动作不能修改该节点。 |

## 上下文命令

输入 `/` 显示菜单，继续输入可筛选；上下键选择，Enter 或点击执行，Escape 关闭。Shift+Enter 保持换行，中文输入法确认不会执行命令。

- `/clear`：清除当前场景的聊天、摘要、历史方案与参考图，同时移除输入中的待发送参考图。无需配置模型；画布、生图模型选择、面板宽度和开关状态保持。
- `/compact`：调用当前对话模型整理目标、最新纠正、硬约束、精确文字、参数与待办。历史聊天仍可查看，完整最新 Prompt Plan 和参考图身份单独保存，后续请求使用摘要与新对话；生图模型选择保持。

行为参考 [Codex 命令文档](https://learn.chatgpt.com/docs/developer-commands?surface=cli) 中以简洁摘要替换早期轮次的 `/compact`。CainFlow 的实现兼容现有 OpenAI 与 Google 对话协议，使用可读语义摘要；[Responses 原生 compaction](https://developers.openai.com/api/docs/guides/compaction) 则返回需要原样复用的不透明压缩项，两者的请求格式与实现不同。

存储保持 version 1，新增可选 `contextSummary`、`archivedMessages` 和 `compactedMessageCount`。归档仅供展示；边界之前的原文已由摘要覆盖，不再发送。旧存档中尚未被语义摘要覆盖的归档原文仍会参加下一次模型压缩。摘要后新增消息进入 `messages`；不再自动裁切消息或生成截短记忆，旧 `memory` 原样保留至模型摘要成功。

压缩服务仅发送文字与图片身份、名称、原消息序号，长输入按序分批，每批记录 JSON 不超过 12000 字符，前批摘要参与下一批，最终摘要不超过 3000 字符。只有全部批次成功且上下文未变化，才写入摘要并推进边界。失败、取消、清空和切换场景时丢弃过期结果；运行中的生成卡片保留。

回归覆盖重复压缩、跨保存恢复、旧原文不重复进入后续请求、历史参考图序号、超长完整草稿、压缩期间新增消息、迟到响应和取消。2026-10-20 共 121 项相关测试通过，包含生产面板的浏览器测试及三种主题的 300px / 612px 布局。使用受控模型响应验证状态流转；真实摘要质量依赖所选模型，可用下表继续评估。

## 缓存面板与入口

缓存面板单独显示 Agent 缓存：已打开场景合计、当前场景占用、消息数、参考图数、生成图数，以及当前有效上下文、归档和摘要数量。占用是 Agent 快照的 UTF-8 JSON 大小估算，包含未保存修改和参考图文本；生成结果只保存有序媒体引用。它不等于去重媒体文件空间，也不扫描已关闭的工作流存档。实时当前快照覆盖同一 Workflow identity 的旧状态，清空后旧快照不会被重复统计。

打开面板、更新对话、压缩、清空和场景切换时刷新本地统计，不等待磁盘媒体审计。面板打开期间沿用定时刷新；关闭其他场景后，也可重开面板立即更新合计。压缩保留归档，不能把模型上下文缩短误报为清理历史存储。

## 真实模型评估

在 Agent 面板选择待评估的对话模型，记录模型 ID、协议、是否支持图片输入和回复。每组独立场景使用新工作流；多轮场景保留同一工作流。下表只评估回复，不必点击生成；节点创建与执行使用上面的验收场景。每次更改规则或对话模型后重跑，按下表记录通过/失败及原始回复。

| 场景与准备 | 用户输入 | 通过条件 |
| --- | --- | --- |
| 选中已有生图节点 | 电影感和胶片感有什么区别？先别写提示词。 | 直接解释，无 Prompt Plan 和应用按钮。 |
| 没有选中节点 | 帮我画一只橘猫在窗边晒太阳。 | 直接起草，不要求先选节点或回答尺寸、风格问卷；已选择生图模型时生成动作可用，点击后才自动创建节点并执行，未选择时提示选择模型。 |
| 详细新需求 | 一只白猫，背景纯黑，文字必须是“晚安。”，其他不要加。 | 保留数量、颜色和逐字文字，不增加道具、口号或冲突的“无文字”限制。 |
| 节点已有城市夜景 | 重新开始，给我一张极简陶瓷杯产品图。 | 新画面不混入旧城市、夜景或旧主题限制。 |
| 上传含红色建筑的图片 | 只参考这张的配色，画一只全新的猫。 | 新建意图；图片为参考，画面不强制保留建筑和原构图。 |
| 上传人物照片 | 只把背景换成雪山，人脸、衣服、姿势都别动。 | 图片为编辑目标；完整提示词明确保留人物，未连接时提示接入目标节点。 |
| 没有图片、节点或既有对象 | 把这张图的背景改成雪山。 | 只询问必要目标图片，无伪造编辑方案。 |
| 单独上传图片，无此前任务 | 无文字 | 询问希望如何使用图片，不自动假设保留主体生图。 |
| 两张输入图片 | 保留第一张的人物，只参考第二张的笔触，别带入第二张背景。 | 两个输入角色明确，人物身份与参考风格分开，不互换图片。 |
| 点击加号，先勾选场景中靠后的图，再勾选靠前的图 | 参考图 1 的配色和参考图 2 的主体。 | 按缩略图上显示的勾选序号理解，不能按画布节点或选择器排列顺序取图。 |
| 上一轮发送两张参考图，本轮重新勾选且顺序相反 | 这次参考图 2 的构图。 | 使用本轮序号；如明确说“上一轮的第 2 张”，则使用上一条消息的序号映射。 |
| 先要求红车海报、标题“出发！”，不应用；节点仍是城市图 | 车换成蓝色，标题不变。 | 使用上一版草稿，保留完整标题，返回完整蓝车提示词。 |
| 先要求 16:9、两张同主题变体，不应用 | 再暖一点，其他不变。 | 保留仍未应用的比例、次数及其他约束；只改光线/色调。 |
| 上轮发过照片，这轮不发图片 | 还是刚才的人，把背景改成室内。 | 沿用历史图片；不会因本轮无附件假装没图或猜测人物。 |
| 先给出主体、精确标题与禁止事项，多轮修订后执行 `/compact` | 改为黄昏，其他不变。 | 延续最新方案，保留主体、逐字标题、禁止事项与参数；不得退回节点旧提示词。 |
| 先发送两张图并明确角色，执行 `/compact` 后保存并重新打开工作流 | 继续用之前第 2 张的配色。 | 通过旧消息序号映射找到相同图片，沿用其参考角色；聊天历史可查看。 |
| 节点旧负面提示词为“文字、水印” | 海报上加标题“夏日”。 | 消除与标题冲突的负面限制，同时保留仍适用的水印限制。 |
| 节点不支持透明背景参数 | 给这张产品图抠出透明背景。 | 说明当前节点能力限制，不伪造参数、不换模型、不把棋盘格当透明。 |
| 对话模型明确不支持视觉 | 上传照片并要求描述图中内容 | 如实说明无法看图，不编造人物、颜色、构图等细节。 |
| 同一构图的多个变体 | 同一只杯子给我三张变体。 | 使用节点支持的 count=3，不声称已生成；与三个不同主题区分。 |
| 多个不同画面 | 分别给我猫、山、水杯三张图。 | 说明每幅需独立方案及当前覆盖内容，不把三者拼成一张或声称全部完成。 |

长历史使用 16,000 字符的普通消息预算，图片二进制不进入文字预算。超出预算的普通历史整条省略并标注；Workflow Memory 仅作有损背景。最新完整 Prompt Plan 始终保留，即使单条超过普通历史预算；它随工作流保存和清空。

## 自动收起及模型浮层（prompt-agent#025）

- Agent 激活不撑开顶部工具栏；保持按钮 active/aria-expanded。顶部唤出、固定及其他展开菜单继续生效；阅读 Agent 时不触发顶部边缘自动唤出。
- 左键空白单击关闭面板但保留草稿和运行状态。节点、连线、导航及右键不关闭；超过 5px 的拖动即使返回起点也不关闭。
- 对话／生图菜单同步原 select，生图仍手动设置。验证选中标记、禁用与删除模型、单菜单互斥、Esc/Tab/点击外部关闭、方向键及确认操作。
- 浮层优先向上，不足时向下，长列表内部滚动，窗口边缘不裁剪；关闭面板清理浮层。加号 SVG 水平垂直居中，面板表面色与画布可区分。

## Token 阈值自动模型压缩（prompt-agent#038，替代 #037 本地字符整理）

- 对话模型新增 `autoCompactTokenLimit`，默认 12000 Token，可设置正整数；留空恢复默认。圆环与触发使用同一 `measurePromptAgentContext`，展示 `≈百分比` 和估算用量/阈值，不是模型容量或累计 API 消费。
- 本地估算覆盖实际上下文投影：系统提示、活动消息、摘要、完整最新方案、素材目录和图片数量。文本使用离线 BPE 分词（o200k_base / cl100k_base），消息封装另计；已知图片模型按图片尺寸和模型规则估算，无法识别时明确显示预留。接口返回实际输入用量后，以其校准相同模型和图片批次的文本增量。不计算 Base64 长度，不承诺未知供应商的 tokenizer 一致。空会话包含系统提示，清空后不一定为 0%。
- 发送前、回复后达到（大于或等于）阈值时，调用当前操作固定的对话模型生成摘要。自动与手动共用模型压缩服务；长记录分片分批完整交给模型，所有批次成功后才提交摘要。
- 消息、记忆和请求历史不再按字符上限截短/省略。历史原文归档但仍可查看，参考图及最新完整方案独立保留。旧存档中未覆盖的原文继续参加压缩。
- 自动压缩前失败：原上下文、待发送草稿保留，不发送普通请求。回复后压缩失败：已完成回复和原文保留。可以重试发送或 /compact。取消、清空、工作流切换、压缩期间对话变化时丢弃晚到摘要。
- 压缩后摘要/最新方案/素材仍超过阈值时明确提示，不循环调用，不删除保留内容。压缩期间新输入的下一条草稿和新附件不能被本次发送清除。
- 自动化覆盖共享 Token 阈值边界、原文保留、模型调用顺序、失败、取消/清空/切换、配置保存、最新方案和参考图；生产面板浏览器验证自动触发、摘要续聊、三主题窄面板。
- 对齐的是 Token 阈值触发模型语义压缩的流程；不宣称本地估算或 JSON 摘要与 Codex 私有实现、Responses 加密压缩状态完全相同。


## 更精确的上下文计数（prompt-agent#039）

- 文本直接计算真实请求中的消息字符串，包括系统指令、摘要和完整方案，避免额外序列化请求封装造成重复计数。按已知模型选择 o200k_base / cl100k_base，特殊 Token 字样按普通用户文本处理。
- PNG、JPEG、GIF、WebP 从本地头部读取尺寸；已知 GPT-4o/4.1 图片规则按切片或补丁计算，未知格式、远端图和未知模型显示“图片含保守预留”。不为计数下载远端图。
- OpenAI prompt_tokens、Google promptTokenCount 校准本次输入（包含缓存部分，排除输出和累计 total）。相同模型配置及图片批次后续按文本分词增量估算；换图、换模型后失效。压缩、清空和工作流恢复均清除校准，不保存临时图片 URL 到会话。
- 圆环仍为达到自动压缩阈值的进度，提示包含具体计数依据；界面和自动触发共用计数。无供应商精确计数时保留 ≈ 标识，不伪称所有模型均精确。
- 回归覆盖中英文/日文/emoji 分词、特殊文本、完整长历史、图片尺寸及规则、接口用量、失效条件、工作流隔离和三主题生产面板。
- 依赖固定 gpt-tokenizer 4.1.0，离线包、许可证与可复现构建步骤见 js/vendor/tokenizer.README.md。图片规则依据：https://developers.openai.com/api/docs/guides/images-vision 。


## 最新成品续改（prompt-agent#040）

- 普通 edit/refine 续改默认绑定最新已完成且有资产的批次，不能因旧导入图仍选中/连接而回退。单张直接绑定，多张必须提供明确序号/对象，否则澄清。
- 模型返回 targetSelection（latest/explicit/prompt-only）；explicit 和 prompt-only 必须引用当前用户原话作为 evidence。明确选旧图/新附件和仅改提示词遵循用户意图。此字段由模型解释语义，受控回归不代表所有真实模型都能准确分类。
- 最新批次原图通过 Media asset 读取进入模型请求；读取失败/缺失停止，不读缩略图替代。读取期间切换工作流、清空或会话变化，丢弃晚到结果。
- 首次完成时记录 completionOrder，保存重试保持不变；压缩归档和恢复保留，旧存档按消息/批次顺序兼容。删除画布生成节点不影响独立结果资产。
- 相同像素合并时保留最新生成身份；同一批相同像素的不同序号仍可区分。已确认方案固定引用资产，不因后来生成改变。

## 联网搜索与搜图（prompt-agent#042）
