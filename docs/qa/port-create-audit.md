关联：`image-assistant-prototype#020`。2026-10-27，基线 `7c53110`。

## 真实应用检查范围

使用真实应用、真实鼠标拖放和隔离的工作流／媒体存储。创建路径不替换内部实现，也不请求外部模型。每个可见端口遍历菜单中全部兼容节点候选，逐次检查：

- 新连接保留准确的拖出端口，另一端属于新建节点，两个端口实际存在且类型兼容。
- SVG路径两端与实际端口中心对齐；无需移动节点或缩放画布才能显示。
- 保存的连接类型来自实际输出端口，`any` 输入不会把来源类型改为 `any`。
- 两条预置参考连接的ID、来源、目标、类型和顺序完整保留；清理临时新节点后仍保留原连接。

## 查明并修复

1. 视频创建菜单读取静态首帧定义，实际模型可能仅支持`referenceImages`。现在按新节点实际使用的默认模型及协议投影筛选端口；点击时重新解析当前候选。
2. 自定义参数`any`输入反向拖线没有候选，且原类型校验把“拖出端”和“输入端”等同。现在按实际输入／输出方向校验，允许任意输入接收具体类型，并保存具体输出类型。
3. 复位颜色节点漏注入`setupColorReset`，新建和恢复会初始化失败。补接已有媒体控制器实现。
4. 动态来源端口消失或输入容量已满时，旧流程会先建节点，再产生无效线或留下孤立节点。现在在创建前核对来源可见性、类型、当前候选、输入支持及容量。
5. 已连接单输入开始重连时会立即删旧边，放弃后无法保留。现在旧边保留到合法替换提交；取消、失焦或失败不修改旧拓扑，成功提交仍受原边和目标的运行锁定限制。
