# Agent 当前任务、参考图和滚动状态（prompt-agent#052）

## 设计

主动有效发送开启跟随并立即滚到最新位置；用户向上滚动终止跟随。ResizeObserver 处理消息与图片后续增高，恢复历史和后台消息仍遵守阅读位置。

画布上下文使用节点真实端口定义。旧 image_N 参考图端口在方案入口统一为 referenceImages，保留顺序；连接组一次性替换，避免多图逐条替换丢失前图。应用后记录输入清单，执行前重新比较资产、节点与顺序。实际请求仍走公共图执行入口，不另外注入候选图片。

creativeTask 是会话的结构化要求，不从模型建议或选中节点推断。支持尺寸、数量、画质等已有参数。回复提供带原文依据的 taskUpdate；歧义新任务或多步骤作用域要求澄清。压缩不删除该记录，清空会话删除；旧方案保存合并后的参数快照。步骤设置仅绑定对应步骤身份。
