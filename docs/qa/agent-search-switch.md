## 开关轨道回归

修复前通用思考输入框 min-height 将 16px 开关撑到 28px，滑块未居中。排除 checkbox 的通用最小高度，并固定开关盒模型、清除默认 margin/padding。七主题实际渲染验证 28×16px 轨道、圆点垂直居中及点击命中；思考控件回归通过。

动画回归：正常动态效果下，切换后 60ms 滑块处于两端之间。旧实现即使 transition 为 0.2s 也直接跳到终点；修复摘要刷新重建浮层的问题后通过。测试明确模拟 no-preference，避免宿主的减少动画设置影响结果。

用户反馈实际界面仍无动画：全局关闭装饰动画规则会清掉普通开关过渡。联网开关标记为功能动画，保留减少动态效果系统设置。删除联网说明和思考程度底部重复的当前设置说明；错误仍显示。

对照顶部工具栏后改为相同的轨道与滑块 DOM，验证七主题中轨道 30×18px、滑块居中、点击命中以及切换 60ms 时位于起止位置之间。
