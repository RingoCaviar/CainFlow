# 复制、删除与撤销的参考连线核验

关联：`image-assistant-prototype#021`。2026-10-27，基线 `c7a5207`。

## 入口与边界

主入口是隔离工作流、隔离媒体存储下的真实应用浏览器操作。复制、菜单粘贴、普通粘贴、Ctrl+Shift+V、克隆、删除、Alt保留连线删除及撤销／重做都经过正式UI入口。图片生成仅在外部请求边界提供受控响应；存储、媒体引用、图操作和恢复均使用正式实现。

| 流程 | 检查结果 |
| --- | --- |
| 全部15类节点复制／删除／撤销／重做 | 新副本保持类型、名称和禁用状态；原参考图的连接ID、端点、顺序完整不变 |
| 单节点和多选粘贴 | 普通粘贴保留内部连线；菜单及Ctrl+Shift+V在同一工作流内恢复可用外部连线；混合内外部参考按原顺序合并 |
| 克隆携带上游 | 完整保留多个参考来源及显式顺序，不再当作单输入仅复制一条 |
| 动态图像／文本合并节点 | 先恢复快照的输入端口数量，再还原连线；粘贴、克隆、撤销及重做都保留第二路及后续输入 |
| 普通删除来源 | 只移除所选节点及其关联边，其他来源不被误断；撤销精确恢复旧连接ID与顺序 |
| 保留连线删除／摘取 | 支持多个相连的中间节点，把上游有序接回原参考位置，保留其他来源的相对顺序 |
| 目标容量不足 | 删除前使用独立连接数组预检；端口、权限或容量无法完整保留时不删除、不修改原图与历史 |
| 运行端点 | 空闲节点如果连接到运行中的端点，也不能删除／摘取；携上游克隆不能漏掉运行来源后仍显示成功 |
| 跨工作流、重复节点ID | 复制来源记录工作流身份，外部边不会自动接到另一工作流中的同ID节点；内部边仍可复制 |
| 已生成图片批次 | 复制完整持久资产列表和顺序；删除原节点、撤销／重做、保存重开后，副本原图仍可读取 |
| 导入写盘期间复制 | 复制时尚未生成持久资产的原图保留内联兜底，粘贴后经正式导入流程落盘，最终资产身份相同 |
| 剪贴板媒体保护 | 独立临时记录在新保护成功后替换旧记录；不随撤销栈清空／淘汰释放，替换剪贴板或正常退出时释放 |
| 视频与保存节点 | 统一收集顶层／嵌套图片、videoAssetKey、video.assetKey、videos[].assetKey；保护、恢复检查和释放共用规则 |
| 已缺失媒体恢复 | 图片与视频分开检查；移除缺失视频的当前引用，保留存活视频的相对顺序，不用视频ID回填图片字段 |
| 远端任务隔离 | 独立副本保留已完成媒体，清除当前imageTask／videoId及并发请求进度，避免续接或取消原节点任务 |
| 节点配置 | 复制复用保存与撤销快照；补齐ColorReset白平衡和色彩参数，避免删除恢复后参数重置 |

## 修复依据

每类已确认缺陷均先通过最小真实UI用例复现，再修改对应路径；视频资产保护通过现有运行时保护API的红到绿回归确认。没有修改后端所有权模型：剪贴板与撤销使用独立的会话临时记录，正式工作流保存继续通过现有媒体提交入口。

普通复制仍生成独立节点，显式克隆仍保留参数跟随语义；不将剪贴板或撤销栈持久化为跨重启的操作历史。外部边因端口不可用或运行锁定被跳过时保留已有节点的连线并提示，跨工作流外部边明确提示未自动连接。
