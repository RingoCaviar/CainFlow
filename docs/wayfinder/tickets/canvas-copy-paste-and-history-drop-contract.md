## Question

Where may users copy and paste workflow nodes, and what happens when they drag a History image onto the Canvas?

## Resolution

The user confirmed: right-clicking Canvas whitespace offers paste at the pointer location. Right-clicking a node offers copy, paste, and delete. Existing keyboard shortcuts remain supported. Dropping a History image on the Canvas creates an Image import node at the release point and does not remove the source History image.
