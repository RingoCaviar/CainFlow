# Agent 供应商选择与请求统计

本地 Issue：`prompt-agent#048`、`prompt-agent#049`。

## 选择与保存

对话、生图、专用搜索和方案步骤共用选择菜单适配器。每个模型仅提供“模型名 · 供应商名”的明确绑定选项，不提供按优先级选项。原生 `select.value` 仍是模型 ID；适配器先同时更新模型及供应商偏好，再派发一次 `input/change`。刷新、恢复及打开菜单不产生保存。菜单和触发器不包含地址或密钥。

工作流会话的 `providerSettings` 按 `chat/image/search` 和模型身份保存显式供应商 ID；没有记录（包括旧存档）表示未选择供应商，显示“请选择供应商”并阻止请求，即使只有一个供应商也不自动选择。切回模型恢复该用途的偏好，清空和压缩保留偏好，切换工作流恢复各自记录。生图仍须手动选模。步骤使用 `providerOverrides[stepId][modelId]`，缺省继承面板；旧记录中的显式空字符串表示未选择，须重新选择，不继承面板供应商。选择“面板模型”恢复继承。

`resolveAgentProvider` 是 Agent 专用严格入口，不使用节点下拉框的默认回退。显式供应商必须仍绑定模型、存在且具有有效 HTTP(S) 地址及密钥；失败返回明确原因和配置目标。未指定供应商时不按绑定顺序解析。失效偏好保留，用户可以修复配置或重新选择。

## 请求与画布应用

对话操作在开始时复制模型、Provider、Agent 思考覆盖、专用搜索偏好及工作流身份。普通回复、画布详情后的追问、自动压缩及搜索后整理沿用这份快照。专用搜索保留自身模型默认思考参数及供应商选择。搜索菜单与请求共享供应商可用性和思考参数校验；运行中修改设置只影响下一次操作。

方案应用通过 `ensureTarget(plan, {modelId, providerId})` 配置新建或绑定节点。供应商变更进入变更清单、相关节点基线和批量撤销；已有节点下拉框回退不能改变 Agent 选择。生图依旧通过公共运行入口，执行快照固定配置，重试复用节点，撤销供应商变更不清除 Agent 已保存图片。

## 统计边界

统计服务增加 `recordRequest`，原 `recordNodeRequest` 作为兼容入口。记录包含独立请求 ID、`source`（`canvas/agent`）、`purpose`、模型 ID、供应商 ID、工作流 ID及既有状态字段。旧记录缺少来源时解释为画布请求。同一 ID 幂等登记，重试使用新 ID；保留既有按日存储、保留期限和数量上限。

Agent 的统一请求追踪包裹每次 HTTP 调用和响应读取：`chat`、`canvas-followup`、`web-search/image-search`、`search-summary`、`compact`。配置/参数校验和预取消发生在派发前，不计数；发出后的失败或取消计失败。响应之后的方案校验、图片保存和 UI 错误不改变该次请求记录，也不新增请求。清空或切换工作流不抹去已发生的调用。

Agent 生图沿用执行核心的原请求记录，由独立运行上下文补充 `source=agent`、`purpose=generate` 及原工作流 ID，Agent 控制器不重复登记。本地画布读取、原图读取和图片下载不计数。统计面板显示请求总数、成功率、供应商排行及画布/Agent 数量分布，不新增费用或 Token 账单。

验证见 [QA](qa/agent-provider-selection-statistics.md)。
