# Canvas MCP 操作已保存的工作流

Canvas MCP 通过本地服务按 Workflow identity 读取、编辑和运行已保存的工作流。编辑和运行提交读取时的版本。工作流写入沿用文件锁和素材所有权提交，防止打开的编辑器或并发调用覆盖已经提交的版本。本机令牌和回环地址校验沿用 [画布能力规范](0025-scoped-canvas-automation.md)。

本地服务启动 Node.js 运行时，复用画布投影、方案校验、执行计划与供应商协议。运行记录和结果归属本地服务，关闭或刷新窗口不影响这些记录。编辑器继续维护实时画布与本轮选区，重新打开时按工作流 ID 读取已保存的版本并保留可恢复的草稿。

本决策更新 [ADR-0024](0024-local-canvas-mcp.md) 对当前编辑器、租约及运行结果归属的约定。本地 Issue 为 `canvas-mcp#002`。
