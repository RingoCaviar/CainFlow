# Keep runtime Media protection separate from persistent workflow ownership

ADR-0010 is narrowed by this decision. CainFlow keeps the workflow document and `replaceMediaOwnerReferenceList` transition record as the sole seam for persistent Media asset owners. Preview and forwarded runtime projections remain temporary protection adapters because they follow runtime visibility and background-run lifetimes rather than saved workflow intent; their direct reference calls must not be mistaken for persistent ownership writes. The existing storage transition recovery, storage-epoch fencing, and `needs-reconciliation` states remain authoritative for persistent commits. Future work must test the interaction between the two lifetimes, but must not collapse them into one state machine without a new failure model and migration proof.
