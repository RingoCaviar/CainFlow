# Let Agent plans use current selection and preview node deletion

The user explicitly asked to remove the separate “插入目标引用” action and let the Agent decide whether to modify, create or delete nodes using the current selection and request. Each send captures the active workflow and its single, multiple or empty selection before asynchronous context preparation. Selected nodes, explicit mentions and uniquely named targets are eligible for proposed mutations; a selected generation node also makes its editable prompt source eligible for a prompt revision. Selection alone never executes a change or selects generation reference images, and an unrelated new task can still create new nodes.

This supersedes ADR-0019's selection-only mutation restriction and deletion exclusion. Canvas action plans retain their preview, explicit application, field whitelist, running locks and atomic save/undo boundary. The additive `deletes` list names exact node identities, with their names and incident connections retained in the preview. Deletion is not cascading: only those nodes and their direct edges are removed, while remaining references keep their identity and order. Failed saves restore the graph before chat references are pruned; successful deletion, editing and creation share one undo entry. Redo restores the graph without execution, and changing selection after submission does not retarget an existing proposal.
