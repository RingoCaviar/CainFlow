# 生成结果自动保存与目录历史

日期：2026-11-01。关联：image-first-canvas#075。

## 决策

生成图片与视频的每个成功结果必须先写入当前保存目录的独立文件，再提交为节点成功输出。前台、后台、Agent 和批次共用生成执行入口。正常保存静默；下载或写盘失败作为本次执行失败反馈。已有的手动下载入口保留。

保存目录默认为应用旁 exports，也可在设置里更改。历史扫描当前目录及子目录中的全部受支持图片和视频，包括用户自行放入的文件；不遍历符号链接、目录联接或快捷方式。以后切换目录只切换视图和新结果目的地，不搬动文件。切回原目录重新扫描即可浏览。

目录原文件不属于可清理的 Media asset 缓存：删除节点、清空 Agent、缓存维护及数量/年龄修剪都不删除原文件。历史中的删除与清空操作明确告知用户会删除本地文件，并且只有实际删除成功才报告成功。文件在确认后发生外部修改时拒绝本次删除，要求刷新后再次确认。缓存中的共享副本继续遵守 ADR-0008/0009/0010/0020 的所有权规则，不因删除原文件而强删其他工作流使用的副本。

## 迁移与元数据

目录媒体库使用独立 SQLite 索引关联文件位置和生成元数据，原文件是浏览与删除的权威来源；索引并非媒体缓存。外部文件自动登记，外部修改后清除不再可信的生成元数据与缩略图。索引按目录区分，切换回来保留未被外部修改文件的提示词、模型等信息。

启动读取历史时，将旧历史记录的图片与视频复制到保存目录。旧历史自动修剪停用，失败时保留旧缓存原件和元数据。迁移先登记待完成写入，写临时文件、同步并校验内容、无覆盖发布，再标记完成；重启继续未完成项。已登记完成或明确删除的旧记录不会反复导出，同名用户文件另取文件名避让。旧缓存的共享所有权不因迁移而强制解除。迁移失败在界面告知，可在目录恢复后重新读取历史重试。

## 保存节点弃用

ImageSave 不再出现在新建菜单或 Agent 的可用节点类型中，也不允许新建。旧文档仍可恢复，以便用户取消清理时保持场景完整。检测到旧保存节点后弹窗说明弃用及自动保存机制；确认才清理全部保存节点，按图片/视频端口接续上下游并保留参考顺序，作为一次可撤销修改保存；取消不改场景。保留旧节点期间仅传递媒体，不再重复导出。

这替代 ADR-0016 中的自动补建保存节点安排；其 Agent 结果独立保留及共享缓存保护规则继续有效。

## 验证边界

使用临时保存目录、隔离工作流与受控模型响应。覆盖写盘完成前不发布、整批保存、写入失败、目录切换与回切、真实文件预览与删除、迁移失败重试/同名/重启、防止目录链接越界，以及旧节点清理的确认/取消与接续。无真实供应商调用，不操作用户的实际媒体文件。
