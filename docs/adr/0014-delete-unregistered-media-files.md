# Delete unregistered Media files instead of quarantining them

This decision supersedes ADR-0008 only for Unregistered Media files. A file with no matching asset metadata path is disposable cache material: startup integrity scanning, manual cache cleanup, and background maintenance remove it regardless of filename, age, or formal collection mode. Old quarantine files explicitly tagged `unregistered-<digest>` are removed too. Deletion rechecks the current asset table under the same SQLite write lock used by asset publication, stays inside the managed directory, and triggers a fresh integrity scan before publishing a clean report. If the database schema is unreadable or unsupported, the file cannot be classified reliably and deletion waits. Registered Media assets retain their owner, safety, and quarantine rules. An interrupted write may lose its only physical copy; the disk-space preference is intentional.
