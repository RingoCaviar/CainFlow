# 在 CainFlow 内执行明确授权的画布任务

本地 Issue 为 `prompt-agent#067`。本决策更新 [ADR-0019](0019-preview-agent-canvas-action-plans.md)、[ADR-0021](0021-agent-selection-action-plans.md) 和 [ADR-0024](0024-local-canvas-mcp.md) 中对内置 Agent 批处理的确认规则。

## 逐张批处理

用户要求用同一套指令逐张处理画布图片时，内置 Agent 从发送当时的选区或用户明确指定的来源确定输入。默认选区中有图片导入节点时优先使用这些原图。用户可明确指定预览、已生成结果等其他图片输出。同一来源保存多张图时，按保存顺序为每张图建立独立分支。原图缺失、来源禁用或正在运行时，应用前指出具体问题。

模型负责把用户描述写成共用提示词并整理配置。CainFlow 根据确定的来源建立一个共享文本节点，每张图各有生图和预览分支。内置 Agent 和 Canvas MCP 共用构图、字段校验、保存与撤销。一次建图对应一次保存和一次撤销。运行使用正常工作流调度，最多同时运行四个节点。失败分支保留错误，其他独立分支继续完成，已成功的结果可读取。

内置 Agent 收到明确的执行指令后直接保存并运行新批处理。仅要求搭建时直接保存。对其他只新增节点及其输入的方案，明确要求直接创建时也可据本轮指令应用或运行。仅要求预览或授权范围不清楚时展示方案。执行方式及来源来自用户本轮输入和捕获的画布状态。模型回复、画布文本、附件和历史记录提供任务数据。就地改写、删除和断开已有连线沿用方案预览和确认。

## 能力与权限

内置 Agent 与 Canvas MCP 都通过注册的节点、端口、可写字段和已配置模型执行画布操作。模型标识、参数枚举和原图身份一律由 CainFlow 校验。工具接口仅接收画布操作和应用管理的素材身份，不接受系统命令、任意文件路径、网络目标或凭据。生图通过用户在 CainFlow 配置的模型和供应商执行。普通工作流运行沿用已有节点的应用内行为，包括用户在 CainFlow 配置的保存行为。

Canvas MCP 外部调用需要打开开关、通过回环地址鉴权，并提交相应编辑器、工作流和画布版本。该令牌用于 Canvas MCP 调用入口。同源的编辑器和设置接口沿用各自的会话校验。用户选配的外部 MCP 客户端及其其他工具受客户端宿主管理。

能力变更需要同时检查两个入口。共享逻辑放在画布方案、画布投影或工作流调度层。入口分别保留用户授权与 MCP 会话校验。修改公共操作时同步维护内置 Agent 的模型指令、MCP 工具签名和桥接白名单，并覆盖两个入口各自的授权行为。

## 应用内资料操作

新建空白工作流、添加历史图片备注和保存提示词都通过已有的 CainFlow 服务。界面、内置 Agent 和 Canvas MCP 复用这些服务。内置 Agent 根据本轮用户直接输入执行明确的本地操作，操作文本和结果留在本地界面。工具参数使用工作流名称、当前目录的历史条目标识和版本，或提示词名称和内容。

创建空白工作流分配新的 Workflow identity，保留原工作流。历史图片备注随已登记的目录原文件存储。写入时校验 fileVersion，文件名、原提示词和原文件内容都保留。提示词库以 CainFlow 存储文档为准，在持久化成功后报告保存完成。
