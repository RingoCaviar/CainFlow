# 本机画布 MCP

CainFlow 的实时画布由编辑器持有。外部 MCP 客户端通过独立的 stdio 进程连接本机编辑器。画布设置中的开关会立即启停回环桥接和直接读写、运行权限。开关状态和令牌保存在服务端私有目录。用户复制客户端配置时才返回令牌。一个服务实例维护一个当前编辑器租约。读取得到编辑器 ID、工作流 ID 和画布版本，编辑和运行都要提交这些值。编辑器、工作流或画布版本变化后，客户端需要重新读取。

MCP 编辑复用现有图校验、保存和批量撤销。一次调用为一个事务。MCP 连接已获得直接编辑权限，画布内置 Agent 继续使用 [Canvas action plan](0021-agent-selection-action-plans.md) 的预览与确认。运行使用现有工作流调度，通过独立的运行 ID 返回状态和有限的文本及图片结果。运行记录与图片缓存归属发起运行的编辑器，保留至编辑器刷新、关闭或缓存淘汰。
