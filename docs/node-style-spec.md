# 节点样式规范

以图片导入、图片生成节点为标准样板。沿用本次 Live 已确认的样式；后续图片类节点按相同规则扩展。本文约束视觉与布局，不改变节点的数据、端口和执行语义。

## 1. 节点本体

| 项目 | 统一规则 |
| --- | --- |
| 表面 | 保留当前主题的节点底色；空白区域不透出画布网格。不固定为白色，不新增主题外颜色。 |
| 边框与阴影 | 常态无装饰边框、无装饰阴影；图片内部不再套第二层边框或卡片。 |
| 圆角 | 复用 `--radius-node`，默认回退 12px；图片与外壳圆角一致。 |
| 内距 | 图片展示区域为 0；图片贴合节点边缘。 |
| 图片 | 保持原始宽高比，完整展示，不拉伸、不为填满节点裁切。 |
| 标题 | 常态隐藏；选中时浮在节点上方，不占用图片区域。名称、启用和删除操作沿用原组件。 |
| 端口 | 保留真实连接与类型；图片节点输入、输出端口分别位于左右边缘，端口组垂直居中。 |
| 空状态 | 节点名称在空白表面居中；加载、缺失文件、恢复与失败信息必须保留真实含义。 |

“无边框”只取消装饰。选中强调、键盘焦点、运行和错误反馈必须清楚，不能全部消除；同时避免叠加多重描边与光晕。

## 2. 节点参数浮层

| 项目 | 统一规则 |
| --- | --- |
| 开启 | 选中节点后显示对应参数；复用原控件，不创建另一份独立状态。 |
| 顶部 | 无标题栏，无右上角放大及关闭按钮；组件保留可访问名称。 |
| 位置 | 水平对齐节点中心；接近左右边缘时限制在视口内。 |
| 垂直锚定 | 目标位置为节点下方，常规间距 12px；到达底部边界后停止下移，不自动翻到节点上方。触底后允许与节点重叠。 |
| 尺寸 | 使用屏幕坐标，不随画布缩放改变文字大小；生图默认宽 560px，导入默认宽 280px，窄窗口以可用宽度为上限；保留已保存的手动宽度。 |
| 视口边缘 | 常规至少留 12px，避让实际展开的工具栏及现有浮动操作。 |
| 内容顺序 | 主要编辑内容在前，模型、模式与其他配置集中在下方；详细设置按需展开。 |
| 溢出 | 内容区内部滚动，执行底栏保持可达；不撑破屏幕，不自动平移画布。 |
| 收起 | 保留 Esc 收起与已有参数恢复入口；切换节点显示新目标的原始控件和状态。 |

浮层使用主题面板表面，圆角 16px，取消外层描边，以阴影区分画布层级；提示词输入框保留可见的弱化 1px 边框、主题输入底色和 6px 8px 内距。普通设置控件保留弱化的输入边界、选中状态与清晰键盘焦点。

## 3. 图片导入样板

**画布：**空状态显示“图片导入”；有图片时只展示原图缩略图。文件选择按钮、分辨率和 URL 字段放进节点参数浮层。

**浮层顺序：**居中的“上传 / URL”切换 → 当前模式的输入控件 → 尺寸与来源信息。

- 上传模式显示全宽文件选择按钮；URL 模式显示原 URL 输入及其操作，不显示文件选择按钮。
- 字段间距 8px；文件选择按钮最小高度 34px，内距 6px 10px，圆角 6px。
- 尺寸信息为次要文字，无额外底框；没有独立生成动作，不添加空底栏。
- 保留拖放、文件读取、URL 加载、错误与缓存恢复行为。

## 4. 图片生成样板

**画布：**空状态显示“图片生成”；生成后以结果图片为主。多图浏览、原图查看、下载和交给助手沿用真实结果操作，不压缩或丢失完整批次。

**浮层顺序：**全宽无标题文本输入框 → 固定底部单行：尺寸入口、紧凑模型选择、更多设置、次数、生成按钮。移除“让助手优化”功能入口。

- 提示词：14px、行高 1.65；默认 2 行，随内容自动增高至最多 6 行，超过后框内滚动；删短后缩回，旧手动高度不覆盖此限制。
- 标签与普通控件：13px；普通输入最小高度 34px。内容分组间距 12px，设置入口间距 8px。
- 模型选择位于底栏，次数紧邻生成按钮左侧；长模型名称截断并保留完整提示。尺寸入口只显示宽高比、分辨率及实际尺寸读数/自定义宽高；模型入口只显示模型和供应商。底栏的“更多设置”独立容纳参考图、质量、搜索和高级参数。弹层内没有分类页签或切换其他设置的入口。
- 底栏设置入口显示当前比例与分辨率（如 `3:4 · 1K`），自动值显示“自动”；自定义分辨率显示实际宽高。模型入口单击打开，再次单击关闭；关闭后重开仍显示模型页面。
- 每个入口一次点击直接打开自己的设置；打开期间点另一个入口直接切换，不先吞掉一次点击。再次点击同一入口关闭。Esc 或点击外部先收起弹层，Esc 返回实际打开它的入口。弹层避开三个入口，保留内容内部滚动。
- 提示词与输入正文可选择复制；按钮和折叠入口文字不因双击被选中。
- 所有窗口宽度只保留一行底部操作，不额外铺设参数行；生成按钮与常规配置入口统一 34px 高，编辑框保留“提示词”可访问名称，不显示额外标签行。
- 编辑、选择模型、展开设置均不自动生成。运行锁、真实进度、取消保护和错误详情沿用既有机制。
- 生成次数大于 1 时，空闲按钮显示“生成 ×N”；次数为 1 时显示“生成”，运行期间仍显示真实运行状态。次数可在底栏直接加减或输入；窄窗口或手动收窄浮层时，尺寸、模型、更多、次数、生成始终处于同一底行。设置入口按容器空间缩为“尺寸”“模型”，完整值保留在悬停提示、可访问名称与菜单内；不依赖换行或横向滚动。
- 次数编辑采用约 82px 宽的单框紧凑步进器，减号、数值、加号共享外边界；隐藏重复的可视“次数”标签，保留“生成次数”可访问名称、悬停提示及键盘焦点。
- 生图底栏入口、次数组和生成按钮统一 34px 外高；尺寸入口按文字与箭头紧凑占宽，常规最大 124px，不与模型入口平分空间；模型入口使用剩余宽度。次数组与生成按钮约 82px 宽，控件间距 8px。设置选单圆角 16px，字段采用 8px/12px 网格间距并顶端对齐；极窄视口收紧底栏横向间距，保留入口文字可读。
- 设置选单中的模型与供应商、宽高比与分辨率分别两列同排，窄窗口不统一退化成单列。“更多设置”按质量、背景、内容审核的顺序同排等宽；模型只支持其中部分控件时，可见控件平分一行，搜索开关沿用模型能力显隐。短协议选择、数值与开关沿用半宽布局；文本、说明和显式全宽字段保留整行。实际请求尺寸、自定义宽高及校验提示保留整行。
- “更多设置”宽度最多 400px，贴近底栏更多入口并限制在视口内。参考图使用 64px 方形缩略图网格、8px 间距、限高滚动；不显示来源名称、张数行或排序工具条，来源信息保留在悬停提示和可访问名称。序号叠在缩略图右下角，不占独立行。右上角断开按钮在悬停或键盘聚焦时显示，触摸设备保持可达。拖拽任意缩略图按整组来源排序；关闭按整组断开连线，保留上游节点、图片和其他连接并可撤销。Alt+左右键排序、Delete断开、Alt+Enter定位来源，预览关闭和排序后恢复缩略图焦点。系统提示词与短选项间隔 12px，全宽、浅色边框，默认两行并随输入增长至最多六行；思考设置在支持时保留底部原位折叠。
- 键盘打开二级选单时，焦点进入当前组的首个可用控件；无可用字段时聚焦当前分组入口，Esc 返回打开选单的入口。鼠标打开不强制转移焦点。
- 自定义选择器的可访问名称包含参数名和当前值，次数输入保留“生成次数”名称；协议字段的视觉标签与对应控件关联，不增加常驻视觉标签行。

## 5. 验收

文本输入节点沿用同一外壳：无装饰边框、无阴影、主题底色不透明，标题选中时浮于上方。输入输出端口位于左右边缘且垂直居中，不保留占高度的端口文字栏。正文直接在节点内编辑，14px/1.65、12px 内距；保留文本选择、键盘焦点、多条文本导航和原始连接语义，不增加无内容的节点参数浮层。

### 文本节点的选择与编辑

- 默认处于画布操作状态。单击正文只选中节点，不进入输入或文字选择；从正文拖动应移动节点，保留画布多选行为。
- 双击正文明确进入编辑；键盘聚焦节点后，Enter 或 F2 也可进入编辑。进入后才显示文本光标，允许输入和选择复制。
- Esc 或焦点离开编辑区结束编辑，保留已输入内容，恢复单击选择与拖动移动。
- 克隆与运行锁继续限制编辑，不因双击绕过；端口、节点按钮、多条文本导航仍执行各自操作。

- 在现有七种主题中，底色、文字、输入边界和状态强调均来自语义变量。
- 空白、单张、多张、长提示词、加载、失败与缺失媒体状态都能正确表达。
- 画布缩放不影响浮层字号；靠近四边时，字段与执行入口仍可达。
- 标题栏和右上角工具不出现；图片没有额外白边，节点背景没有变透明。
- 修改参数不改变节点坐标、端口身份、连接顺序、原图或批次数据。

主要实现：`css/features/image-first-canvas.css` 与 `js/features/ui/image-first-canvas.js`。如旧文档与本文冲突，以本文及后续明确确认的设计决定为准。

下拉选项菜单使用独立顶层浮层，不能被节点、参数选单或滚动区裁切。根据触发器上下可用空间选择展开方向，宽高限制在视口内；长列表内部滚动，最后一个选项仍可点击。滚动与窗口变化时重新定位，关闭时清理监听器；保留父子选单与原始控件关系。

生图参数浮层不显示“设置待生成”提示行；底层参数变更与生成结果状态继续保留。


参数入口属于只读导航，节点运行时仍可打开“更多设置”查看参考图；输入与连接修改继续服从原有运行锁。关闭参考图原图预览后，应在模态层解除后恢复“更多设置”及原缩略图焦点。下拉菜单已展开时缩小窗口，应在父浮层完成定位后重新对齐触发器，并保持选项处于视口内。

更多设置采用有悬停说明和读屏名称的省略号图标按钮，外高与底栏统一为 34px；文本框恢复全宽。窄面板收紧入口间距、次数输入和生成按钮宽度，五项操作保持单行。
