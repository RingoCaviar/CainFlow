# 画面风格节点

画布上的「画面风格」只显示风格摘要，不放参数控件。点击节点打开参数浮层，在唯一的「风格描述」文本框中输入或修改内容。手动输入不需要配置模型。

将风格输出连接到图片生成或电商套图。同一个风格可连接多个节点，每个目标只接一个风格。商品、主体参考图与任务提示词继续连接到生成节点；风格参考图连接到风格节点。

## 从图片提取

连接风格参考图，在浮层的「提取模型」中配置支持图片输入的模型与供应商，然后点击「提取风格」。结果直接替换风格文本框，可以继续手动修改。提取失败保留原文并显示原因。修改文本和普通工作流运行均不会自动调用分析服务。

「提取精细度」有五档，默认标准：极简用一句话抓住画风；概括提炼主要色调与氛围；标准补充光影、质感和构图；详细描述配色关系、光线与空间层次；精细进一步描述视觉要素之间的配合。档位控制描述的详略程度，实际篇幅取决于图片与模型。切换只影响下次提取，不改写现有文本、不重新生成图片；设置随工作流保存。

只保留整体风格文本，移除预设、逐维度编辑、提取范围和单独排版入口。旧工作流中的结构化风格会完整显示为文本，首次编辑后以该文本为准，不再叠加隐藏的旧配置。

## 生效与版本

普通生图在请求中使用当前风格；电商套图在规划和生成中使用它。主体身份、商品固有颜色与结构、图位要求和确认文案优先于风格。风格参考图只用于提取描述，不作为下游主体图。

运行期间锁定编辑。修改不会自动生图：普通生图标记参数已变更，电商套图提示重新规划；保留已有成图、定稿及当次风格快照。提取效果取决于所选模型。
