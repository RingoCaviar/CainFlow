# 画面风格节点

在画布添加「画面风格」，选择预设或填写风格描述。展开「视觉细节」可分别设置表现形式、配色、光影、质感、背景、构图与避免项。「图文排版」只作用于任务要求的文字，不新增文案。

将「画面风格」输出连接到图片生成或电商套图的输入。同一个风格可连接多个节点，每个目标只接一个风格。主体、商品参考图与任务提示词继续连接到生成节点；风格参考图连接到风格节点。

## 从图片提取

连接风格参考图，展开「从参考图提取风格」，选择提取维度、支持图片输入的分析模型及供应商，然后点击「提取所选风格」。这会调用模型并替换所选字段，其他字段保留。提取只分析视觉表达，不将参考图作为下游商品或人物来源。提取结果可继续编辑。

普通工作流运行输出当前配置，不自动调用风格分析。更换参考图后，需要主动重新提取；当前风格描述继续有效。

## 生效与版本

普通生图在请求中使用风格规范；电商套图在方案规划、逐图生成和追加场景规划中使用它。主体身份、商品固有颜色与结构、图位背景要求和确认文案优先于风格。

工作流运行期间，风格设置暂时锁定，运行结束后恢复编辑。修改风格不自动生图。普通生图沿用已有的参数变更标记；电商套图提示重新规划与确认，保留旧成图和定稿。生成快照随工作流保存，套图候选的提示词详情包含所用风格。重新规划时已定稿图位保留原来的方案、风格和成图，解锁后可以更新。

首版通过预设和可编辑描述控制风格，不保证不同模型输出完全一致。风格参考图用于提取文字规范，不作为图像风格适配器直接发送给下游生图服务。
