# Agent 尺寸设置与澄清

本地 Issue：`prompt-agent#050`。

## 规则

尺寸按钮位于 Agent 底部操作行，打开独立设置浮层。分辨率、比例使用共享选择菜单；自定义尺寸按需显示宽高。未设置字段为“跟随方案”，与接口的空字符串“自动／默认”区分。选项及请求尺寸映射复用 image-generation-size。

优先级按字段为：用户对澄清的回答 → 方案明确字段 → Agent 当前模型尺寸偏好 → 已绑定且模型相同的节点值 → 接口默认。切换生图模型时不继承另一模型的节点尺寸。面板是默认值，不能覆盖方案的明确要求；模型收到默认值及当前模型的尺寸能力，提示词要求省略未指定字段。

OpenAI 尺寸协议在自动分辨率下无法指定比例；程序保留比例草稿、显示中文原因和可选分辨率，不补 1K。自定义尺寸由宽高决定，必须符合既有尺寸规则及明确要求的比例。Google 等允许默认分辨率和比例并存的协议不受该限制。单独提供宽高但未选自定义，以及不支持的档位或比例均阻止应用，不静默丢弃。

## 接口和状态

- `resolveAgentSize` 接收协议、节点现值、面板默认值及方案补丁，返回规范补丁、最终尺寸和摘要；需澄清时携带 `sizeClarification`（类型、可选值、原比例）。
- `aspect` 与 `aspectRatio` 在边界归一，同一回复中冲突时拒绝。Prompt Plan 使用 aspectRatio，Canvas Plan 使用 aspect。
- Conversation Store 新增可选 `sizeSettings`，按模型身份保存分辨率、比例及自定义宽高。缺字段不迁移、不推断；clear/compact 保留，工作流恢复替换各自设置。
- Canvas Plan 保存 `agentSizes` 和步骤 `sizeAnswer`；应用记录 `appliedSizes`，执行记录保存实际 size。已执行方案不随面板默认值刷新历史尺寸。
- `sizesFor` 在素材读取和画布事务之前校验所有生图步骤，应用时先写分辨率再写比例及宽高。新节点与已有节点空宽高采用同一表示，重复应用不会多产生撤销步骤。
- 单步旧方案使用相同解析；不能升级为 Canvas Plan 的旧卡片也提供尺寸澄清和待确认状态。

## 交互与生命周期

尺寸菜单复用主题表面、焦点与父子菜单协调；菜单向上优先展开并限制在视口内。关闭 Agent 或切换工作流关闭浮层。按钮显示紧凑尺寸摘要，未选模型时说明需先选择。

用户可点击方案中的档位按钮或在输入框回复“2K”“用2K”“1536×1024”等短答案。仅最新仍存在且待澄清的方案消费这类答案，更新原方案并保存；不会额外请求模型、创建节点或开始生成。其余对话按正常模型流程处理。模型请求固定发起时的尺寸上下文；运行固定点击时的实际尺寸配置。清空、切换工作流及运行中的方案不能被晚到回答修改。

尺寸信息包含在实际输入和上下文计数中；不改变供应商手动选择、结果媒体所有权或请求统计规则。
