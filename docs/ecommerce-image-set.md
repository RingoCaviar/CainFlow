# 电商套图节点

1. 在画布添加「电商套图」，连接 1 至 5 张同一商品的原图。点击节点，在画布右侧设置参数。底栏可打开「连接参考图」菜单，也可定位已连接但尚未输出图片的来源。第一张原图作为商品首图的主要依据。
2. 选择平台、支持图片输入的规划模型和供应商。没有可选模型时，从底栏进入模型配置。在「产品信息」里可选填产品名称、核心卖点、适用人群、使用场景，以及已核实的规格或包装清单。点击「分析产品」可根据参考图和已填资料补全字段，无需先选图位。分析结果可随时手动修改。
3. 在「整套美术风格」填写表现形式、配色、光影和整体氛围，也可留空让 AI 在规划时先确定统一风格。自动风格会显示在输入框中，可直接修改，或点「重新由 AI 设定」后再次规划。连接「画面风格」节点时优先使用连接的风格。各图位沿用共同视觉语言，按用途自由变化构图、景别和信息节奏。修改风格需重新规划，已有成图保留。
4. 在「生成设置」选择「图中文字语言」，分别设置「主副图」与「详情图」的比例并勾选需要的图位，再点「生成方案」。未勾选时可用底栏的「选择图位」定位。规划时会自动分析商品并把结果填回「产品信息」，手填内容优先。规划后仅取消部分图位时，保留剩余图位的方案、手动文案和原有确认状态，可直接制作；保存后重新打开仍沿用该范围。加入未规划的图位，或更改语言、比例、商品定位、参考图及画面风格后需重新规划，节点在新结果产出前保留上次套图。
5. 方案生成后，从第一个生图图位开始检查核心卖点和各图位的画面设计。支持文案的图位各有一个多行文本框，可一起填写标题、正文、卖点和排版要求，无字数上限。确认后的文案保留换行并交给生图模型。文案留空时省略叠字。
6. 选择支持参考图和所选比例的同步生图模型和供应商，查看底栏的预计模型调用和图位范围，再确认生成。完成后，缩略图显示主副图或详情图文成品，点击可打开全屏预览。结果先按主副图、后按详情图显示，并通过「套图输出」按顺序传给下游。模型生成的图片保存到当前保存目录。图位提供「重写方案」和单图生图操作，后者使用该图位的当前提示词及适用的文案要求。

各图位独立显示进度。一个图位运行时，可以继续编辑、规划或生成其他空闲图位。点击图位旁的「取消」停止对应任务，或点击参数面板底部的「取消全部」停止当前节点正在进行和等待中的任务。重新生成期间可以继续预览该图位的上一张成图。

修改图位文案或生图提示词后，原成图仍可预览，状态显示「待更新 · 显示上一版」。按当前方案生成新图后，提示自动消失。

部分生成失败时，节点和运行通知会提示完成数量。可在底栏选择「补齐」，只处理未完成的图位。

有成图后可点击图位上的「定稿」。「重做已确认图位」会沿用定稿图片及其输出位置，并跳过待规划或待确认的场景。方案修改后可使用「确认方案并重做」，底栏仍显示重做范围。点击「解锁」后可以继续编辑、规划或替换。改变定稿图位的比例、移除此图位或切换平台前，先解锁受影响的图位。

每个生图图位最多保留 20 个已保存版本，包含当前图片。可通过「生成候选…」打开候选弹窗。已有候选时，点击「对比 N 张候选」可并排查看图片，并检查各自的文案和提示词。采用成图候选时，会恢复对应文案和提示词。

## 详情长图

选择详情图位后，规划模型会根据商品、卖点和风格参考，给出整页的配色、字体层级、光影、视觉元素和阅读顺序，以及每个图位如何与上下画面衔接。生图请求带上整页设计要求、当前图位的构图及文案。模型在一次出图中完成商品画面、文字和排版。

在详情图分组可以按阅读顺序预览模型成图。可以在图位卡片编辑文案，或在预览中用自然语言调整整页或单屏方案，例如「把第二段标题移到图片右上角」。确认新版方案后，重新生成需要更新的图位。

套图输出按页面顺序提供各图位的模型成图。在「导出套图」选择「详情图」，可以按顺序打包原图 ZIP。旧工作流可以继续查看已有成图，解锁并重新生成相应图位即可采用新版提示词。

在「生成设置 → 每图位生成」选择 1 至 8 张，默认 1 张。单图生成、补齐图位和整套生成时，每张候选单独调用生图模型。沿用原图的图位和已定稿图位不增加模型请求。首张成功图作为当前成图，其余成功图在候选弹窗中选择。

从图位或套图面板取消时，会停止余下的候选请求。已有当前成图会继续选用，本轮成功的候选仍可在保存后查看。模型请求结束后，面板会显示「正在保存成图」，直到本轮结果可用。

套图方案生成后，可以从「主副图」或「详情图」分组连续添加场景图。每次追加一个图位，沿用该组比例。可填一句场景描述，也可留空由 AI 根据商品资料、参考图和已有场景推荐。先点「生成方案」，查看并编辑画面提示词和文案，再点「确认并生图」。补充场景单独运行和取消，原有方案、成图与相对顺序会保留。尚未确认的场景草稿可以继续编辑，套图生成和补齐仍可处理其他图位。

修改无关的预设图位后，追加场景仍沿用已有草稿。场景的商品资料、参考图、比例或图中文字语言变化后，保留草稿，检查后可再次确认。手动改写生图提示词时，卡片预览和后续场景推荐使用当前提示词。单独生图保留同一组参考图下其他兼容图位的成图，已有成图可能标为「上一版」。

套图任务结束后，点击追加场景图卡片右侧的垃圾桶并确认，可从套图方案、输出和导出中移除该场景。定稿的场景需先解锁。

有成图后，点击「套图方案」旁的「导出套图」，预览全套、主副图或详情图。列表会标出缺图和会随包导出的上一版成图。确认后按套图顺序生成 ZIP，每张图沿用原始格式，以「两位序号_图位名」命名。缺图跳过，其他图的序号保留。

更换或重排商品参考图后，面板会提示重新规划。可点击「预览上次套图」查看旧成图，或在导出时明确选择「上次套图」。当前套图的输出和导出以本次参考图为准。旧工作流的参考图版本无法核实时，重新规划后可继续使用。

「图中文字语言」默认为「自动」，优先参考商品资料中的语言要求，亚马逊默认英语，其他预设默认简体中文。选择具体语言后，新方案及重写图位会用它撰写图上文案。已确认的手动文案原样交给生图模型，原图中的商标和包装文字按原样保留。

## 风格参考图

将画布上的图片输出连到电商套图的「风格参考图」端口，或在节点参数浮层展开「风格参考图」，点击「添加参考图」，从当前场景或目录历史选一张原图。直接选取的图片会随工作流保存，可预览、替换和移除。连线会随上游图片更新，断开连线即可移除该来源。

每张参考图都可以指定用途。选择「不指定类型（整套）」时，所有需要生成的图位共用这张风格参考。选择具体主图、副图或详情图时，只有对应图位使用它。商品参考图仍决定商品外观，风格参考图用于构图、配色、光影及图文节奏。

实际生图时，商品原图、整套风格参考和该图位的专属参考合计最多 5 张。替换选取的参考后，已有成图可继续查看，检查方案后再确认制作。采用历史候选时会恢复该图位的草稿和专属选图，整套参考和画布连线沿用当前设置。

## 平台预设

主副图默认 1:1，用于商品列表、轮播及附图。详情图默认 9:16，包含详情首屏、核心卖点说明、细节与做工、场景与用法，可按需用于详情页。两组比例可独立修改，直接沿用的实拍图保留原始尺寸。发布时按实际类目、活动和站点核对尺寸、背景、首图及商品信息要求。

- 淘宝／天猫以商品和可核实卖点为重点，自主选择商业主视觉的构图。展台、场景、装饰、标签、信息卡及底部信息带均为可选手法，不要求每张重复同一套布局；整套统一美术风格，各图位保持自己的展示重点与阅读节奏。「白底素材」单独生成纯白背景、无叠字的商品图。设计案例见[国内电商主图的美术指导](research/domestic-commerce-main-image-art-direction.md)。具体类目和活动要求以发布入口为准，资料依据见[主图设计核对记录](research/taobao-main-image-design.md)。 [淘宝开放平台公告](https://developer.alibaba.com/support/announcementDetail.htm?id=25721)
- 京东提供商品主图、多角度、卖点、细节和场景图。 [京东视觉设计](https://jdrdl.jd.com/Design-image.html)
- 拼多多提供轮播首图、多角度、细节、卖点和场景图。活动和类目要求请在商家后台核对。 [拼多多商家后台](https://mms.pinduoduo.com/)
- 抖音电商使用第一张实物原图作为首图，生成其余图位。准备清晰的方形原图，通用指引为至少 600 × 600 像素。 [抖音电商商品主图发布规范](https://school.jinritemai.com/doudian/web/articlev0/ahean96xqddv)
- 亚马逊新方案默认以第一张商品原图生成白底精修 MAIN，保持商品身份、包装文字和真实数量，完整展示商品，不添加叠字、道具或营销场景。MAIN 的摄影与白底要求优先于整套海报、插画等风格；副图和详情图采用共同美术风格。旧方案保留原图首图行为，也可在「亚马逊 MAIN」切换为「生成白底图」后重新规划。案例与一手资料见[亚马逊套图美术指导](research/amazon-image-set-art-direction.md)。 [亚马逊商品图片指南](https://sellercentral.amazon.com/help/hub/reference/external/G1881?locale=en_us)

候选弹窗以缩略图网格展示历史版本，单击缩略图选中对比。方图、横图和长详情图在对比区完整缩放显示。点击当前成图或选中候选的大图可进入全屏预览、缩放和左右切换，返回后保留选中状态。历史达到上限时保留当前采用的版本，淘汰较早的其他版本。

弹窗的「本次生成」初始显示节点每图位的默认张数。可选择 1–8 张，仅用于这一次追加，每张单独调用模型。成功结果追加为候选，当前成图与套图输出在采用候选后更新。生成时底栏显示本轮状态和「停止生成」入口，部分成功或重复图片会显示实际新增数量。已定稿图位须先解锁。候选追加、查看候选草稿和采用候选通过参数面板操作。内置 Agent 与 Canvas MCP 沿用共享执行逻辑及既有公开字段。
