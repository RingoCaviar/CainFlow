# 电商套图节点

1. 在画布添加「电商套图」，连接 1 至 5 张同一商品的原图。点击节点，在画布右侧设置参数。若预设使用实拍首图，将准备上传的实物图放在第一张。
2. 选择平台、支持图片输入的规划模型和供应商。商品资料可填入已核实的尺寸、材质、颜色或包装清单。
3. 分别设置「主副图」与「详情图」的比例，勾选本次需要的图位，再点「生成方案」。更改图位或比例后需重新生成方案，节点在新结果产出前保留上次套图。
4. 检查商品卖点和各图位的画面设计。提示词可调整主体、构图、风格和文字摆放。支持文案的图位会把确认后的标题和正文一并交给生图模型排版，留空可省略对应文字。
5. 选择支持参考图和所选比例的同步生图模型和供应商，再确认生成。每张完成后直接显示模型返回的成图，点击右侧缩略图可打开全屏预览。结果先按主副图、后按详情图显示，并通过「套图输出」按顺序传给下游。成功图片保存到当前保存目录。图位状态旁的文档图标重写这张图的方案，图片图标则用当前文案和提示词单独生成这张图。

## 平台预设

主副图默认 1:1，用于商品列表、轮播及附图。详情图默认 9:16，包含详情首屏、核心卖点说明、细节与做工、场景与用法，可按需用于详情页。两组比例可独立修改，直接沿用的实拍图保留原始尺寸。发布时按实际类目、活动和站点核对尺寸、背景、首图及商品信息要求。

- 淘宝／天猫提供商品主图、卖点、细节、使用场景和白底素材。官方发布入口按类目区分方图及竖图。 [淘宝开放平台公告](https://developer.alibaba.com/support/announcementDetail.htm?id=25721)
- 京东提供商品主图、多角度、卖点、细节和场景图。 [京东视觉设计](https://jdrdl.jd.com/Design-image.html)
- 拼多多提供轮播首图、多角度、细节、卖点和场景图。活动和类目要求请在商家后台核对。 [拼多多商家后台](https://mms.pinduoduo.com/)
- 抖音电商使用第一张实物原图作为首图，生成其余图位。准备清晰的方形原图，通用指引为至少 600 × 600 像素。 [抖音电商商品主图发布规范](https://school.jinritemai.com/doudian/web/articlev0/ahean96xqddv)
- 亚马逊预设以美国站公开指南为参考。MAIN 使用第一张实拍原图，准备纯白背景、无叠字且完整展示商品的照片，建议最长边至少 1,000 像素。其余图位使用模型生成。 [亚马逊商品图片指南](https://sellercentral.amazon.com/help/hub/reference/external/G1881?locale=en_us)
