# UI 设计手册

## 图片卡片与节点参数浮层

生图结果去掉重复的“放大”按钮，双击图片仍查看原图；未选中时不显示空操作框，选中后保留参考、助手修改、下载及更多操作。Agent与历史中的图片操作保持原样。

- 图片导入、图片生成、预览、缩放、颜色、对比、合并、保存和视角控制采用图片主体卡片。未选中时省去标题栏，选中标题浮在节点上方；端口仅常显圆点，名称通过悬停和可访问名称保留。已加载的图片或视频按自身比例决定预览高度，完整显示；节点宽度保持，导航与操作另计高度。切换批次或保存媒体类型时跟随当前媒体，浏览不改变完整输出。空结果使用紧凑占位，不把参考图当生成结果。
- 单击图片选中并打开节点参数浮层，双击或放大按钮查看原图。拖动移动节点；对比滑块、取色和局部缩放等专用操作优先于通用点击。视角控制继续打开原独立编辑器，保存节点继续支持视频播放器和独立图片/视频保存。
- 同时打开一个节点参数浮层，单选跟随切换，空白或多选收起。普通模式始终位于节点下方，是画布变换外的独立浮层，初始宽度约480px、正常字号，按实际内容收高、限高内部滚动；角落放大/关闭工具不单独占行，按需展开一组设置。节点参数浮层不撑高卡片，不改变节点或端口坐标，不自动平移画布或翻到节点上方。
- 节点参数浮层的普通宽度可调整并全局记住。主动放大后可拖动、双向调大小，仍为同一组件；切换节点保持本次放大状态，关闭后重开回普通模式。还原返回当前节点下方，值和原控件保留。
- 节点参数浮层与右侧Agent可重叠，点击可见部分置顶；底部“参数置顶/助手置顶”入口可找回完全遮挡的窗口。切换不关闭另一个窗口，不丢草稿、附件、模型选择或后台请求；真实模态仍遮罩两者，Esc和关闭返回有效焦点。
- 生图提示词框内部提供“让助手优化”，不另占一行标题。提示词默认约3行、自动增长至约6行后滚动，用户手调高度优先。模型、尺寸和输入/参考数量入口显示当前值；原次数控件与生成相邻，仍使用原重复执行语义。详情保留所有适用参数、思考、搜索、自定义协议和不同模型草稿，实际请求尺寸与执行使用同一解析规则。
- 有效上游主提示词优先，首次有效内容默认展开；本地原草稿折叠为“本地草稿 · 未参与”，保留内容及原控件，断开后恢复编辑。上游无输出时明确说明，沿用原解析规则，不自动断线或拼接本地稿。修改直接进入当前工作流，关闭节点参数浮层不丢；保存与生成分开，编辑不自动执行。
- 参考图在节点参数浮层中按真实连接分组、紧凑多列排列，批次完整、限高可滚动；保留连续有效编号、排序、定位、原图查看、数量明确的断开及撤销。缺失和禁用来源保留位置；只按需读取原图，不把当前浏览图当完整输出。运行端点锁定，克隆参数只读，参考连线仍按原画布权限处理。
- 来源用途、数量、排序、定位及已有启用/停用保持直接可达；替换和断开收进常显“更多”，原作用范围和权限不变。更多在文档流内展开，Esc先收起并返回入口；断开明确标注来源、用途及完整媒体数量。缩放/调色字段同行排列，保存文件名同行，相机只读摘要紧凑分列、长提示词可展开；导入无空底栏，其他主操作在滚动内容内保持可达。
- 导入的“本地素材/URL来源”说明和保存的媒体数量、输入数及图片/视频切换放在节点参数浮层中，卡片与图片上不重复展示。保存仍保留原视频选择器、播放器及图片批次。生图预览仅留窄边距，图片保持完整显示，端口名称不常显；节点底部不再放独立状态条，状态、真实进度和错误详情进入节点参数浮层，取消仍使用原长按入口。
- “让助手优化”只在草稿与附件均为空时准备明确节点引用；已有内容保留并提供主动插入目标，不自动发送、选模型、应用或生成。Agent编辑有效上游提示词时明确预览真实对象；应用方案原子提交，成功一次撤销，重做仅恢复图。
- 卡片摘要表示当前模型和尺寸。有效提示词、模型、参数及来源/顺序改变时显示“设置已修改，待生成”；完整成功且本轮实际配方一致后解除，失败、取消、部分成功不误清。选择、浏览、置顶与正常重开不误标，也不推测旧图的历史配置。
- 打开旧工作流保留坐标、宽度、手调文本尺寸、标题、启用/折叠、克隆、任务、预览索引和未知JSON扩展；已加载媒体的预览高度按当前比例重新适配，原固定高度不再制造留白。调整节点宽度时高度随比例变化，拖动上下或角落边缘也按媒体比例缩放。对比以必需B图为基准，其他媒体完整包含；没有有效媒体尺寸时保留占位。只读已有预览尺寸，不自动排列或执行。

## 通用输入与真实连线

- 图片相关节点把输入收为一个展示入口，按源输出类型与目标能力解析到既有逻辑用途；保存图继续使用真实规范端口，永不持久化`auto`。导入没有新增虚构输入，纯图片处理拒绝不支持的文本/视频/参数。
- 生图的图片默认参考，Text进入主提示词，CameraControl文本进入视角提示词，CustomParams进入参数。遮罩必须明确选择：新多图遮罩被阻止；旧多图遮罩沿用来源首图兼容语义，新单图遮罩后来变多图则保留连接并阻止新执行。
- 对比依次填空A/B，满位时要求明确替换；B仍必需，交换真实改变A/B并可一步撤销。合并按动态槽位与来源批次完整展开。保存按图片/视频独立角色分流，反向新建可选择尚空的视频用途。
- 输入明细显示真实来源、类型、用途、完整数量及状态。排序、替换和断开保留其他连接身份、扩展和顺序；正反向拖线新建在校验后一次提交“创建+连线”。重复、自连/循环、容量、来源变化、运行锁及取消/失败不留半节点，也不误断旧线。

## 画布顶部工具栏

- 画布统一使用顶部工具栏，左侧不再单独设置工具栏。按品牌、工作流入口、运行控制、创作与保存、工具与设置排序；常驻操作为工作流、运行、停止、保存、历史、Agent、更多和设置。
- “运行”和“保存”使用主操作样式，其余按钮使用较轻的次级样式。功能组用间距与浅色表面区分，颜色从主题语义变量派生，并检查所有七套主题。
- 空间不足时功能组整体换至下一行；极窄窗口下允许组内换行。工具与设置组靠右，保证“更多”菜单的展开位置位于视口内；菜单在低高度窗口内可滚动。
- “更多”按画布工具、资源与记录、帮助与维护分组，包含整理节点、提示词库、缓存管理、请求统计、执行日志、帮助与快捷键、强制刷新和清除画布。清除画布保留原有确认并使用危险色，其余选项不使用危险色。菜单支持上下方向键、Home/End、Esc 回焦、点击外部关闭，执行操作后收起。
- 主题、自动重试和运行通知统一在“设置 → 常规设置”管理，保持原有持久化、通知权限及通知测试。画布只提供一个工具栏固定显示偏好；旧左栏固定偏好不再产生布局空隙。
- 撤销和重做使用 Ctrl/Cmd+Z、Ctrl/Cmd+Y、Ctrl/Cmd+Shift+Z，不在顶部保留按钮。输入框保留原生文本撤销；快捷键在帮助内可查。
- 保留画布工具栏的自动收起、悬停展开和固定行为；抽屉从左边缘展开，不预留旧左栏空间。对话 Workspace mode 使用独立操作布局，通过设置访问主题。
- 工作流入口旁显示当前工作流名称及“有修改 / 待保存 / 已保存”，读取现有工作流记录与编辑状态；名称可截断，悬停显示全名。工具组仅用间距分隔，避免组外框叠加按钮边框。

## 设置与画布导航

- 常规设置按“外观与画布、生成与运行、通知、高级”切换，记住当前会话的分类；分类支持方向键与 Home/End。卡片按内容自然高度排列，窄窗口改为单列。
- 保存目录放在生成与运行的前部；Agent 压缩、旧数据迁移、诊断、更新归入高级。普通偏好自动保存，保存目录单独确认，界面明确区分。关闭自动重试时禁用重试次数及步进，并解释开启后生效。
- 画布导航显示“− 当前比例 ＋｜适应画布”；点击当前比例选择常用比例，100% 标为“原始比例”。比例选择保持视口中心的缩放锚点，支持键盘与 Esc；低高度菜单可滚动，展开时提示消息避让菜单。

## 提示消息

- 不超过 5 秒的普通信息与成功提示只显示最新一条，减少连续启动反馈占用画布。警告、错误、持久进度、长时进度和主动更新的受控提示保留独立展示。
- 替换提示时清理其计时器；旧提示句柄和旧计时器不能移除新提示。警告与错误使用 alert，普通状态使用 status。
- 工作流备份提醒可“本次隐藏”，刷新后仍隐藏，下一会话可再次提醒；保留此前选择永久关闭的偏好。
- 启动联网检测和自动检查更新在后台按原延时执行，不展示倒计时；自动检查无更新时静默。手动检查保留进度和结果，失败及可用新版本仍提供明确反馈。

## 智能对话节点选项

- 普通可编辑智能对话节点的“联网搜索”开关始终可切换，不按模型、供应商或协议禁用；切换模型、保存恢复均保留用户选择。克隆节点遵守既有只读约束。说明中区分可切换的联网偏好与实际请求能力：当前仅 Google 接口编码搜索工具，OpenAI 请求暂不读取此选项；Google 是否实际支持仍由模型服务决定。
- “复用上次回复”说明工作流运行时复用成功回复并跳过此节点及其上游；单独运行该节点可更新回复，首次没有成功结果时仍正常生成。沿用原有 fixed 字段和执行逻辑。
- 两个选项分别使用标题、关联开关和常显短说明，完整语义收在“选项说明”；窄节点内正常换行。支持点击标题和键盘切换；颜色、焦点、边框使用共享主题语义。
- 系统提示语默认折叠，摘要区分未设置与已设置，展开后可编辑。空回复以紧凑占位展示，有内容后恢复正常阅读高度；保留用户保存的文本框与回复区尺寸。
- 回复支持复制及放大查看，放大窗口只读、支持 Esc 与焦点返回。克隆节点保留只读语义，但仍可复制、查看回复。正文及说明保持足够字号与对比。

## 紧凑开关

以顶部工具栏开关为视觉基准，适用于 Agent 联网等即时生效的二态设置。

- 顶部工具栏轨道 30 × 18px、滑块 12px；Agent 紧凑浮层可采用 38 × 22px 轨道、16px 滑块和 16px 行程，让状态变化更清晰。滑块以轨道 50% 高度为基准垂直居中；有边框时扣除边框宽度，避免偏位。
- 标签与开关同一行，整行可点击，高度至少 28px。标签 12px，辅助说明 11px、行高 1.45；不把说明放进轨道。
- 关闭使用主题控件表面色与次要文字色；开启使用主题强调色及白色滑块。使用平面样式，不加发光或浮雕。
- 位置与背景变化使用相同的缓动曲线；Agent 联网开关采用 400ms，让打开和关闭两个方向都能看清滑动。只声明 transform、background-color、border-color，不使用 transition: all。
- 开关滑动属于表示开关状态的功能动画，全局关闭装饰动画时仍保留；prefers-reduced-motion 下缩短到 300ms，不影响设置保存。状态切换动画不延迟业务值更新。
- 使用原生 checkbox 与 role="switch"，提供关联 label、说明和清晰的键盘焦点；Space 可切换。禁用状态必须有实际业务原因，不凭模型厂商猜测联网能力。
- 固定盒模型并清除输入默认 margin/padding，不能继承普通文本框的 min-height。不要依靠 !important 修补冲突。
- 回归检查七套主题、窄面板、开关两态、滑块居中、点击命中、键盘和减少动画偏好。

参考实现：css/modules/01-toolbar.css、css/modules/07-node-controls.css；Agent 适配位于 css/prompt-agent.css。

- 切换开关时必须保留已挂载的控件，不因摘要或提示文字变化重建父浮层，否则 CSS transition 会被打断。动画回归应检测切换过程中的滑块中间位置，不能只检查 transition 声明。

- Agent 联网开关复用工具栏的 `.toggle-switch > input + .toggle-slider` 结构；轨道和滑块分别由 `.toggle-slider` 与其伪元素绘制。不要重新用 checkbox 的伪元素绘制，以免与工具栏的过渡、主题规则分叉。

## 生图结果的继续创作

节点结果、历史详情和助手结果依次提供「放大、用作参考、交给助手修改、下载」，已支持的复制放入「更多」。操作捕获选中单张原图，切换当前查看图片不会缩减输出批次。历史卡片保持紧凑，详情承担完整操作。

用作参考仅准备助手附件，沿用普通图片导入与媒体去重；移除附件保留导入节点。交给助手修改会在空编辑器准备请求，已有文字或附件时保留草稿并提供主动插入。仍需用户发送、选择模型并确认应用方案后才更改生成关系或执行。所有异步操作校验来源与工作流，缺失原图明确提示。

生图节点在结果前显示就近状态；「运行到此」和日志入口沿用右键菜单。运行范围是目标与所需上游，固定上游成功缓存仍生效。等待和运行期间节点控件锁定，取消沿用原长按 2 秒行为，入口放在卡片外状态行，参数锁定时仍可用。节点进入新一轮待运行或运行中时清除上一轮错误摘要、指示和正文，自动重试同样清除；再次失败显示本轮错误，历史日志与运行范围外节点的错误保留。新执行清空当前输出，不将历史图片显示为新一轮结果。

本范围新增正文和常用图片操作从 13px 起；辅助文本可保持较小字号。状态小字使用 text-success/text-danger 等语义文字色，控件使用共享表面、边框和焦点，不为每套主题重复 DOM 样式。高级折叠、来源前后移动、原图预览和更多菜单均保留键盘路径；关闭预览/菜单时回到当前仍有效的控制。原有节点坐标、宽度及用户手调文本/预览尺寸照常恢复，内容增高不触发全图自动排列。

参考图片的连续编号只覆盖参与当前输入的来源；禁用来源保留来源行及数量，并明确标记不参与输入。缺失媒体保留原位置，按稳定资产读取，不将压缩列表里的后续图片替代缺失项。模型切换后保留的不适用思考设置仍提供继承/接口默认入口，允许用户主动清除；不通过隐藏控件清除或绕过设置。


生图失败的卡片红色短原因支持换行和长字符串折行，完整错误在“查看详情”及节点参数浮层中阅读。Agent 修改已有生图节点时默认保留全部参考来源与批次；仅本轮用户明确要求断开、清空或替换参考图时才可移除。旧式提示词方案同样遵循此规则，历史方案在应用前重新检查，不能因生成意图或模型漏列来源而清空连接。


Agent参考图在@节点、选中节点和多轮方案之间使用相同的连接顺序及完整批次。相同像素可以复用传输附件，每个来源/批次位置仍有独立身份；禁用来源保留连线，但不参与当前输入。仅改提示词时按上一方案快照核对原图及顺序，多目标不明确或待执行上游不能用旧图替代时需澄清或保留完整多步骤。失败重试会核对跳过的成功上游：上游已改图或缺少快照时，需完整重新执行；完整重新生成会重新执行计划中的上游。参考原图或顺序变化不能通过刷新检查静默接受，需根据当前画布重新生成方案。验收范围见 `docs/qa/agent-reference-flow.md`。

端口拖至空白画布后，创建菜单只列出可连接的节点；视频输入以新节点默认模型的协议端口为准。自定义参数的任意类型输入可反向创建具体类型来源，新连线记录实际输出类型。来源端口已变化、输入不再支持或容量已满时，创建前提示重试。已有单输入的重连在成功提交前保留原线，取消或失败保留原连接，成功提交可以撤销／重做。完整检查范围见 `docs/qa/port-create-audit.md`。

一次节点粘贴作为一个完整撤销步骤；普通粘贴保留内部连线，菜单或Ctrl+Shift+V可在同一工作流内携带外部连线。跨工作流不按重名ID自动接外部节点。克隆携上游时保留全部参考来源与顺序；保留连线删除会把上游接回原参考位置，无法完整保留时维持原图。运行端点的关联连线受保护。复制保留禁用状态、完整原图批次和配置；独立副本不继承原节点的当前远端任务。剪贴板临时保护图片和视频到替换或退出，不随撤销栈淘汰而释放。检查矩阵见 `docs/qa/canvas-edit-reference-audit.md`。
