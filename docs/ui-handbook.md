# UI 设计手册

## 顶栏执行状态

工作流名称旁单独显示当前工作流的“启动中”“运行中”或“停止中”，多个并行执行范围显示真实数量；无任务时完全收起状态列及其间距，有任务时显示固定宽度的状态列，执行期间切换阶段不改变占宽。工作流名称保留完整悬停说明，窄窗省略。状态与原工作流提示分别呈现，切换画布按稳定工作流身份刷新，不把后台运行显示成当前工作流正在执行。

顶栏“运行”保留独立执行范围的启动能力，启动准备时防止重复点击；“停止”名称不变，只停止点击时当前工作流的全部执行范围，不影响后台工作流。尚未建立可取消运行时停止禁用；等待原图恢复或执行器启动帧时取消，不得随后继续发起请求。停止中禁止重复停止，完成清理后恢复空闲。退出应用仍保留全部运行的取消与结算。

运行中的节点可单独拖动，也可随选区一起拖动。位置和连线随拖动更新，删除、参数修改及输入连线变更仍受运行锁保护。运行结果保存时保留画布上的最新节点位置。

两个按钮保持38px同高、同一像素边框，去掉双光晕和脉冲；运行使用当前主题主操作色，停止启用时使用轻危险色，禁用时为中性色。

## 首次使用与配置引导

空画布常显“添加第一个节点、让助手创建、配置模型”，并保持工具栏展开；添加节点后收起引导，继续使用用户原有的工具栏固定偏好。助手空状态提供只填入输入框的创作示例，不自动发送，不覆盖已有草稿。模型选择、配置提示和常用参数入口字号至少 13px。

模型设置直接展示供应商与模型列表，说明由现有设置帮助提供。没有供应商时添加模型聚焦添加供应商，不创建空模型。名称使用浅底色和可见边框，收起时也可直接改名；点击名称只编辑，标题空白展开或收起，拖动柄负责排序。改名沿用现有保存机制，不改变稳定ID、模型代码或供应商绑定。模型卡继续显示待完善信息，协议请求示例和说明默认折叠；执行前仍校验必要配置，本地完整不代表已验证远程连接。

生图节点参数浮层在模型、用途、兼容格式或供应商地址不完整时禁用生成，并提供配置生图模型入口。工作流执行也在重置节点结果前校验实际运行范围；禁用节点不阻塞。执行错误默认展示原因和建议，技术详情按需展开，仍可复制。

801–1200px 窗口为已打开的助手预留画布空间，节点参数浮层的上下文仅显示当前编辑节点名称。更窄窗口保留浮层前后切换，不把参数区域挤成窄条。打开、缩放助手不自动平移画布。

节点参数浮层上下都不能完整容纳时，优先保留卡片外部结果操作和取消入口，在较宽裕的一侧内部滚动；字号或上下文栏增高不能让浮层盖住这些操作。

单节点取消保留鼠标长按两秒，并支持聚焦后长按 Enter 或空格两秒；提前释放、失焦、切换页面均取消长按。新自动工作流使用“未命名工作流”及不重名后缀；已有工作流不因名称规则变化改名。

## 操作确认与提示

应用内确认和文本输入统一使用项目居中弹窗，沿用当前主题；普通状态继续使用底部轻提示。删除、覆盖等操作使用明确的动作按钮和危险色，默认聚焦取消。取消、关闭或 Esc 不执行操作，等待确认期间重复触发不重复执行。长正文在弹窗内部滚动，操作按钮始终可见。启动失败的重载确认保留独立静态模板，避免依赖尚未加载成功的应用模块。浏览器自身的离页保护仍由浏览器管理。

打包桌面版更新准备就绪后提供“立即重启”和“稍后”，选择稍后仍保留重启入口。重启前检查所有生成和 Agent 任务并保存当前工作；任务运行中、保存失败或重启准备失败均留在应用中，保留编辑和撤销能力。旧进程退出、程序替换成功后才自动启动新版。浏览器访问及非打包环境继续提示手动重启主程序。

## 图片卡片与节点参数浮层

节点参数浮层在打开时确定位置；展开或收起参数组、切换选项及输入文字时保持左上角位置，内容向下增长，超过当前位置的可用高度时内部滚动。移动节点、缩放或平移画布、窗口或侧栏可用空间变化时重新定位；关闭重开、切换节点和还原放大模式时重新确定位置。

节点执行失败时标题栏统一显示可点击的“! Err”标记，合并原感叹号与计时区Err，完整错误查看入口保持；正常运行计时不变。节点折叠功能已移除，标题双击不再折叠；旧工作流的折叠节点打开时自动展开，保存不再写入折叠状态。生图结果只有多张时显示翻页栏，单张不占翻页空间。生图浮层底部次数和生成控件整组居中，不再常显运行状态文字；真实进度、错误详情及取消操作保留。生图浮层不再提供输入菜单或连接节点列表；更多参数只显示生成设置，实际连线通过画布管理，参考图直接显示在提示词上方。生图节点不再显示重复的当前设置与参考数量摘要；统一使用浮层底栏的尺寸、模型和更多设置，参考图位于提示词上方，设置待生成提醒仍保留。生图结果去掉重复的“放大”按钮，双击图片仍查看原图；未选中时不显示空操作框，选中后保留参考、助手修改、下载及更多操作。Agent与历史中的图片操作保持原样。

导入节点参数浮层上传模式按按钮内容收宽，只预留关闭操作的必要间距；URL模式初始宽度280px，独立记住用户调宽，其他节点的宽度偏好保持。上传/URL按钮相对浮层居中，角落工具在右，不再重复显示本地素材或URL来源说明；URL模式在下一行展开原有字段。导入、保存和视角节点不提供放大模式，从其他已放大节点切换到这三类节点时恢复普通模式；其他节点仍可放大。

- 图片导入、图片生成、预览、缩放、颜色、对比、合并、保存和视角控制采用图片主体卡片。未选中时省去标题栏，选中标题浮在节点上方；端口仅常显圆点，名称通过悬停和可访问名称保留。已加载的图片或视频按自身比例决定预览高度，完整显示；节点宽度保持，导航与操作另计高度。切换批次或保存媒体类型时跟随当前媒体，浏览不改变完整输出。空结果使用紧凑占位，不把参考图当生成结果。
- 单击图片选中并打开节点参数浮层，双击或放大按钮查看原图。拖动移动节点；对比滑块、取色和局部缩放等专用操作优先于通用点击。视角控制继续打开原独立编辑器，保存节点继续支持视频播放器和独立图片/视频保存。
- 同时打开一个节点参数浮层，单选跟随切换，空白或多选收起。普通模式优先位于节点下方，下方不足且上方能完整容纳时放在上方，否则在可用视口内平移浮层以优先完整展示；只有内容超过可用视口高度时才内部滚动。浮层位于画布变换外，初始宽度约480px、正常字号，按实际内容收高；角落放大/关闭工具不单独占行，按需展开一组设置。点击参数与布局重算保留滚动位置，底部操作按文档流排列，不吸底遮挡其他参数。节点参数浮层不撑高卡片，不改变节点或端口坐标，不自动平移画布。
- 节点参数浮层的普通宽度可调整并全局记住。主动放大后可拖动、双向调大小，仍为同一组件；切换节点保持本次放大状态，关闭后重开回普通模式。还原返回当前节点下方，值和原控件保留。
- 节点参数浮层与右侧Agent可重叠，点击可见部分即置前并执行本次操作；窄窗保留可点击的露出区域，节点和顶栏Agent分别恢复对应面板。切换不关闭另一个窗口，不丢草稿、附件、模型选择或后台请求；真实模态仍遮罩两者，Esc和关闭返回有效焦点。
- 生图提示词不另占一行标题，默认两行、自动增长至六行后滚动。参考图在上方单行常显，尺寸、模型、更多设置、次数和生成集中在底栏；次数仍使用原重复执行语义。详情保留所有适用参数、思考、搜索、自定义协议和不同模型草稿，实际请求尺寸与执行使用同一解析规则。
- 有效上游主提示词优先，首次有效内容默认展开；本地原草稿折叠为“本地草稿 · 未参与”，保留内容及原控件，断开后恢复编辑。上游无输出时明确说明，沿用原解析规则，不自动断线或拼接本地稿。修改直接进入当前工作流，关闭节点参数浮层不丢；保存与生成分开，编辑不自动执行。
- 参考图在节点参数浮层中按真实连接分组、紧凑多列排列，批次完整、限高可滚动；保留连续有效编号、排序、定位、原图查看、数量明确的断开及撤销。缺失和禁用来源保留位置；只按需读取原图，不把当前浏览图当完整输出。运行端点锁定，克隆参数只读，参考连线仍按原画布权限处理。
- 在支持图片输入的节点提示词或 Agent 中输入 `@`，默认浏览「上游输入」，也可切到「场景图片」选择当前画布的导入图、节点输出或目录历史。图片显示保持比例的缩略图和来源，继续输入可搜索；方向键浏览，Enter 选中，Esc 关闭，Alt+左右方向键切换来源。Agent 仍可切到「节点」指定画布操作目标。
- 节点中的上游引用跟随同一连线和批次位置，场景引用使用所选原图，两者都不会改变节点连线。来源断开、所选位置消失或场景原图被替换后，运行时提示重新选择。Agent 中选中的图片出现在本轮附件栏，随消息发送。
- 已绑定的 `@图片` 在提示词中带主题色标记。悬停 1 秒查看缩略图，点击可打开原来的图片列表并更换这一处引用。键盘可用 Tab 聚焦标记后按 Enter，提示词撤销和重做沿用原生编辑操作。
- 来源用途、数量、排序、定位及已有启用/停用保持直接可达；替换和断开收进常显“更多”，原作用范围和权限不变。更多在文档流内展开，Esc先收起并返回入口；断开明确标注来源、用途及完整媒体数量。缩放/调色字段同行排列，保存文件名同行，相机提示词可按需展开；导入无空底栏，其他主操作在滚动内容内保持可达。
- 保存的媒体数量、输入数及图片/视频切换放在节点参数浮层中，卡片与图片上不重复展示。保存仍保留原视频选择器、播放器及图片批次。生图预览仅留窄边距，图片保持完整显示，端口名称不常显；节点底部不再放独立状态条，状态、真实进度和错误详情进入节点参数浮层，取消仍使用原长按入口。
- “让助手优化”自动加入目标与可编辑提示词来源引用；已有草稿、附件及其他引用保留，不再提供独立“插入目标引用”按钮，不自动发送、选模型、应用或生成。每次发送捕获当前单选、多选或未选中状态，Agent结合用户要求判断修改、新建或删除；选中不强制修改旧节点，也不自动成为生成参考图。Agent编辑有效上游提示词时明确预览真实对象；删除方案列出节点名称、ID和直接连线影响，只移除列出的节点。应用方案原子提交，保存失败回滚，成功一次撤销，重做仅恢复图。
- 卡片摘要表示当前模型和尺寸。模型入口只显示模型名称与当前供应商，长名称和窄窗口沿用尾部省略，悬停及读屏保留完整内容，不扩宽按钮。有效提示词、模型、参数及来源/顺序改变时显示“设置已修改，待生成”；完整成功且本轮实际配方一致后解除，失败、取消、部分成功不误清。选择、浏览、置顶与正常重开不误标，也不推测旧图的历史配置。
- 打开旧工作流保留坐标、宽度、手调文本尺寸、标题、启用/折叠、克隆、任务、预览索引和未知JSON扩展；已加载媒体的预览高度按当前比例重新适配，原固定高度不再制造留白。调整节点宽度时高度随比例变化，拖动上下或角落边缘也按媒体比例缩放。对比以必需B图为基准，其他媒体完整包含；没有有效媒体尺寸时保留占位。只读已有预览尺寸，不自动排列或执行。

## 通用输入与真实连线

- 图片相关节点把输入收为一个展示入口，按源输出类型与目标能力解析到既有逻辑用途；保存图继续使用真实规范端口，永不持久化`auto`。导入没有新增虚构输入，纯图片处理拒绝不支持的文本/视频/参数。
- 生图的图片默认参考，Text进入主提示词，CameraControl文本进入视角提示词，CustomParams进入参数。遮罩必须明确选择：新多图遮罩被阻止；旧多图遮罩沿用来源首图兼容语义，新单图遮罩后来变多图则保留连接并阻止新执行。
- 对比依次填空A/B，满位时要求明确替换；B仍必需，交换真实改变A/B并可一步撤销。合并按动态槽位与来源批次完整展开。保存按图片/视频独立角色分流，反向新建可选择尚空的视频用途。
- 输入明细显示真实来源、类型、用途、完整数量及状态。排序、替换和断开保留其他连接身份、扩展和顺序；正反向拖线新建在校验后一次提交“创建+连线”。重复、自连/循环、容量、来源变化、运行锁及取消/失败不留半节点，也不误断旧线。

生图参考图在提示词上方直接显示无名称行的方形缩略图及叠加序号，可拖拽排序，悬停右上角按钮断开整组来源。来源名称通过悬停和读屏保留；来源启停从画布操作，已禁用来源仍不参与本轮输入，原图片说明数据继续保留。

图片节点输入连接不再显示“更多”菜单，保留用途选择；连线替换和断开从画布操作。

其他图片节点的参数浮层统一收紧间距，无额外反馈时底部操作居中。保存节点去掉输入用途、更新媒体和放大模式；原查看与保存按钮移入浮层，文件名及路径警告保留。仅同时有图片和视频时显示类型切换，多视频保留选择；视角浮层不再显示说明入口和只读参数表，保留相机提示词与编辑视角入口，原参数继续在独立编辑器调整。预览节点无输入时避免在底栏重复提示，异常或过期提示仍显示。

按钮、页签、菜单操作和折叠入口的文字不可双击选中；输入框、提示词、错误详情及回复正文仍可选择复制。

## 画布顶部工具栏

- 顶部品牌使用第三版几何线稿猫头，22px矢量标志跟随各主题配色；应用名称与版本号仍上下排列。

- 单行顶栏50px高，按钮保持38px；顶栏上下内距4px，组内上下不加额外内距。品牌名称与版本号上下排列，标志保留在左侧，整体在38px区域内居中。窄窗按整组换行、行距4px，菜单和抽屉跟随实际高度，不为旧顶栏预留空隙。

- 画布统一使用顶部工具栏，左侧不再单独设置工具栏。按品牌、工作流入口、运行控制、创作、工具与设置排序；常驻操作为工作流、运行、停止、历史、Agent、更多、主题和设置。
- “运行”和“保存”使用主操作样式，其余按钮使用较轻的次级样式。功能组用间距与浅色表面区分，颜色从主题语义变量派生，并检查所有七套主题。
- 空间不足时功能组整体换至下一行；极窄窗口下允许组内换行。工具与设置组靠右，保证“更多”菜单的展开位置位于视口内；菜单在低高度窗口内可滚动。
- “更多”按画布工具、资源与记录、帮助与维护分组，包含整理节点、提示词库、缓存管理、请求统计、执行日志、帮助与快捷键、强制刷新和清除画布。清除画布保留原有确认并使用危险色，其余选项不使用危险色。菜单支持上下方向键、Home/End、Esc 回焦、点击外部关闭，执行操作后收起。
- 主题位于顶栏“更多”与“设置”之间，显示当前主题名与下拉箭头；按钮与相邻操作同高，按最长主题名预留稳定宽度。菜单单列展示七种主题的名称与当前选中勾，选择即生效并保存。菜单展开时顶栏保持可见；支持方向键、Home/End、Esc 回焦、Tab 退出和低窗口滚动。主题控件聚焦时不触发背景画布的节点编辑快捷键。常规设置不再重复提供主题入口。
- 自动重试和运行通知继续在“设置 → 常规设置”管理，保持原有持久化、通知权限及通知测试。画布只提供一个工具栏固定显示偏好；旧左栏固定偏好不再产生布局空隙。
- 撤销和重做使用 Ctrl/Cmd+Z、Ctrl/Cmd+Y、Ctrl/Cmd+Shift+Z，不在顶部保留按钮。输入框保留原生文本撤销；快捷键在帮助内可查。
- 保留画布工具栏的自动收起、悬停展开和固定行为；抽屉从左边缘展开，不预留旧左栏空间。当前只开放画布 Workspace mode。
- 工作流入口旁显示当前工作流名称；停止修改 3 秒后自动保存，正常不显示保存状态，仅失败时提示并提供重试；名称可截断，悬停显示全名。工具组仅用间距分隔，避免组外框叠加按钮边框。

## 设置与画布导航

- 常规设置按“外观与画布、生成与运行、通知、高级”切换，记住当前会话的分类；分类支持方向键与 Home/End。卡片按内容自然高度排列，窄窗口改为单列。
- 顶级设置页签支持方向键与 Home/End；切换页签或分类从顶部开始，分类栏滚动时保持可见。供应商和模型卡片可通过展开箭头进入配置，原名称和铅笔仍直接改名；展开按钮保留焦点并提供真实状态，标题空白点击及拖动排序继续可用。关键字段标签关联输入控件，窄窗完整展示表单。
- 保存目录放在生成与运行的前部；Agent 压缩、旧数据迁移、诊断、更新归入高级。普通偏好自动保存，保存目录单独确认，界面明确区分。关闭自动重试时禁用重试次数及步进，并解释开启后生效。
- 画布导航显示“− 当前比例 ＋｜适应画布”；点击当前比例选择常用比例，100% 标为“原始比例”。比例选择保持视口中心的缩放锚点，支持键盘与 Esc；低高度菜单可滚动，展开时提示消息避让菜单。

## 提示消息

- 不超过 5 秒的普通信息与成功提示只显示最新一条，减少连续启动反馈占用画布。警告、错误、持久进度、长时进度和主动更新的受控提示保留独立展示。
- 替换提示时清理其计时器；旧提示句柄和旧计时器不能移除新提示。警告与错误使用 alert，普通状态使用 status。
- 不再显示“更新前请备份 workflows 文件夹”的常驻通知。
- 启动联网检测和自动检查更新在后台按原延时执行，不展示倒计时；自动检查无更新时静默。手动检查保留进度和结果，失败及可用新版本仍提供明确反馈。

## 智能对话节点选项

- 普通可编辑智能对话节点的“联网搜索”开关始终可切换，不按模型、供应商或协议禁用；切换模型、保存恢复均保留用户选择。克隆节点遵守既有只读约束。说明中区分可切换的联网偏好与实际请求能力：当前仅 Google 接口编码搜索工具，OpenAI 请求暂不读取此选项；Google 是否实际支持仍由模型服务决定。
- “复用上次回复”说明工作流运行时复用成功回复并跳过此节点及其上游；单独运行该节点可更新回复，首次没有成功结果时仍正常生成。沿用原有 fixed 字段和执行逻辑。
- 两个选项分别使用标题、关联开关和常显短说明，完整语义收在“选项说明”；窄节点内正常换行。支持点击标题和键盘切换；颜色、焦点、边框使用共享主题语义。
- 系统提示语默认折叠，摘要区分未设置与已设置，展开后可编辑。空回复以紧凑占位展示，有内容后恢复正常阅读高度；保留用户保存的文本框与回复区尺寸。
- 回复支持复制及放大查看，放大窗口只读、支持 Esc 与焦点返回。克隆节点保留只读语义，但仍可复制、查看回复。正文及说明保持足够字号与对比。

## 紧凑开关

以顶部工具栏开关为视觉基准，适用于 Agent 联网等即时生效的二态设置。

- 顶部工具栏轨道 30 × 18px、滑块 12px；Agent 紧凑浮层可采用 38 × 22px 轨道、16px 滑块和 16px 行程，让状态变化更清晰。滑块以轨道 50% 高度为基准垂直居中；有边框时扣除边框宽度，避免偏位。
- 标签与开关同一行，整行可点击，高度至少 28px。标签 12px，辅助说明 11px、行高 1.45；不把说明放进轨道。
- 关闭使用主题控件表面色与次要文字色；开启使用主题强调色及白色滑块。使用平面样式，不加发光或浮雕。
- 位置与背景变化使用相同的缓动曲线；Agent 联网开关采用 400ms，让打开和关闭两个方向都能看清滑动。只声明 transform、background-color、border-color，不使用 transition: all。
- 开关滑动属于表示开关状态的功能动画，全局关闭装饰动画时仍保留；prefers-reduced-motion 下缩短到 300ms，不影响设置保存。状态切换动画不延迟业务值更新。
- 使用原生 checkbox 与 role="switch"，提供关联 label、说明和清晰的键盘焦点；Space 可切换。禁用状态必须有实际业务原因，不凭模型厂商猜测联网能力。
- 固定盒模型并清除输入默认 margin/padding，不能继承普通文本框的 min-height。不要依靠 !important 修补冲突。
- 回归检查七套主题、窄面板、开关两态、滑块居中、点击命中、键盘和减少动画偏好。

参考实现：css/modules/01-toolbar.css、css/modules/07-node-controls.css；Agent 适配位于 css/prompt-agent.css。

- 切换开关时必须保留已挂载的控件，不因摘要或提示文字变化重建父浮层，否则 CSS transition 会被打断。动画回归应检测切换过程中的滑块中间位置，不能只检查 transition 声明。

- Agent 联网开关复用工具栏的 `.toggle-switch > input + .toggle-slider` 结构；轨道和滑块分别由 `.toggle-slider` 与其伪元素绘制。不要重新用 checkbox 的伪元素绘制，以免与工具栏的过渡、主题规则分叉。

## 生图结果的继续创作

节点结果、历史详情和助手结果依次提供「放大、交给助手、下载」，已支持的复制放入「更多」。操作捕获选中单张原图，切换当前查看图片不会缩减输出批次。历史卡片保持紧凑，详情承担完整操作。

交给助手仅将选中原图加入助手附件，沿用普通图片导入与媒体去重；移除附件保留导入节点。已有文字和附件保持不变，空编辑器不预填修改请求，参考或修改用途由用户输入决定。仍需用户发送、选择模型并确认应用方案后才更改生成关系或执行。所有异步操作校验来源与工作流，缺失原图明确提示。

节点参数浮层的生成、处理和更新按钮只执行当前节点，上游图片完整批次和文本等输入只读缓存；必需参考图缓存缺失时提示失败，不自动补跑上游，生成次数也只重复当前节点。生图节点在结果前显示就近状态；「运行到此」和日志入口沿用右键菜单，「运行到此」的范围仍是目标与所需上游，固定上游成功缓存仍生效。等待和运行期间节点控件锁定，取消沿用原长按 2 秒行为，入口放在卡片外状态行，参数锁定时仍可用。节点进入新一轮待运行或运行中时清除上一轮错误摘要、指示和正文，自动重试同样清除；再次失败显示本轮错误，历史日志与运行范围外节点的错误保留。新执行清空当前输出，不将历史图片显示为新一轮结果。

本范围新增正文和常用图片操作从 13px 起；辅助文本可保持较小字号。状态小字使用 text-success/text-danger 等语义文字色，控件使用共享表面、边框和焦点，不为每套主题重复 DOM 样式。高级折叠、来源前后移动、原图预览和更多菜单均保留键盘路径；关闭预览/菜单时回到当前仍有效的控制。原有节点坐标、宽度及用户手调文本/预览尺寸照常恢复，内容增高不触发全图自动排列。

参考图片的连续编号只覆盖参与当前输入的来源；禁用来源保留来源行及数量，并明确标记不参与输入。缺失媒体保留原位置，按稳定资产读取，不将压缩列表里的后续图片替代缺失项。模型切换后保留的不适用思考设置仍提供继承/接口默认入口，允许用户主动清除；不通过隐藏控件清除或绕过设置。


生图失败的卡片红色短原因支持换行和长字符串折行，完整错误在“查看详情”及节点参数浮层中阅读。Agent 修改已有生图节点时默认保留全部参考来源与批次；仅本轮用户明确要求断开、清空或替换参考图时才可移除。旧式提示词方案同样遵循此规则，历史方案在应用前重新检查，不能因生成意图或模型漏列来源而清空连接。


Agent参考图在@节点、选中节点和多轮方案之间使用相同的连接顺序及完整批次。相同像素可以复用传输附件，每个来源/批次位置仍有独立身份；禁用来源保留连线，但不参与当前输入。仅改提示词时按上一方案快照核对原图及顺序，多目标不明确或待执行上游不能用旧图替代时需澄清或保留完整多步骤。失败重试会核对跳过的成功上游：上游已改图或缺少快照时，需完整重新执行；完整重新生成会重新执行计划中的上游。参考原图或顺序变化不能通过刷新检查静默接受，需根据当前画布重新生成方案。验收范围见 `docs/qa/agent-reference-flow.md`。

端口拖至空白画布后，创建菜单只列出可连接的节点；视频输入以新节点默认模型的协议端口为准。自定义参数的任意类型输入可反向创建具体类型来源，新连线记录实际输出类型。来源端口已变化、输入不再支持或容量已满时，创建前提示重试。已有单输入的重连在成功提交前保留原线，取消或失败保留原连接，成功提交可以撤销／重做。完整检查范围见 `docs/qa/port-create-audit.md`。

一次节点粘贴作为一个完整撤销步骤；普通粘贴保留内部连线，菜单或Ctrl+Shift+V可在同一工作流内携带外部连线。跨工作流不按重名ID自动接外部节点。克隆携上游时保留全部参考来源与顺序；保留连线删除会把上游接回原参考位置，无法完整保留时维持原图。运行端点的关联连线受保护。复制保留禁用状态、完整原图批次和配置；独立副本不继承原节点的当前远端任务。剪贴板临时保护图片和视频到替换或退出，不随撤销栈淘汰而释放。检查矩阵见 `docs/qa/canvas-edit-reference-audit.md`。

连接端口使用36.4px半圆，半圆直边紧贴节点边缘；图片相关节点的左右端口组各自垂直居中，多个输出按组居中；悬停和拖线目标高亮只保留光晕，不缩放端口，路径跟随真实端口中心。

图片相关节点的普通空白预览显示节点名称，并同步自定义名称；载入媒体后恢复图片或视频展示。加载、缓存缺失、恢复和报错提示保留，生图节点仍提供编辑提示词入口。

连线高亮仅跟随当前选中的端点节点；点击空白取消、切换节点或取消多选后及时清除，不受最后操作节点及其关联缓存影响。

面板置顶切换条在Agent打开时居于左侧剩余画布区域；空间不足时竖排，避让画布导航，不覆盖Agent输入或发送区。Agent宽度及窗口变化同步更新位置，关闭Agent后恢复横排。

Agent用户消息在原手动附件之外显示本轮节点引用图片缩略图，按实际读取顺序编号，可点击原图。显示使用发送时独立快照，不新增模型附件、画布连接或执行动作；保存重开保留，后续换图不改旧消息。旧消息没有保存的快照不从当前画布补猜；删除来源节点沿用历史引用清理规则。

常规设置的Agent上下文压缩菜单支持显式选择“模型 · 供应商”，单独记住各压缩模型的供应商，不改变日常对话模型或供应商。“跟随Agent对话模型”同时跟随其供应商；未设置独立压缩供应商的旧配置沿用该模型在当前会话中的有效选择。配置失效仍明确阻止压缩，不自动换供应商，原上下文保留。


## 画布关系与编辑上下文

普通连线保持高于点阵背景的可见度，鼠标进入节点时突出其直接关联，选中时保持明确强调。七种主题沿用同一明暗层级。

生图参考图位于提示词上方：60px方形缩略图单行排列、保留图片比例、序号在右下角；无图收起，多图横向滚动。拖动缩略图按整组来源排序，悬停右上角关闭按钮断开该来源；运行锁与完整批次语义保持。更多设置不再重复包含参考图。

参数浮层和Agent都通过点击直接置前，不再提供底部面板置顶切换控件。点击输入框直接获得光标，点击按钮直接执行；菜单打开时点击另一编辑面板可同时收起菜单并操作。被遮挡的参数可重新点击节点打开，助手可从顶栏Agent按钮恢复。窄窗口保留面板可点击露出区，切换不改变画布和草稿。

生图节点参数浮层采用更饱满的控件密度：底栏统一 38px 高、14px 文字，参考缩略图 60px，提示词 15px/1.55 且保留浅边框。常规宽度 560px、圆角 16px；内容外围、参考图到提示词、提示词到底栏以及底栏控件之间的可见间距统一为 6px，常规与窄窗一致。通过利用现有留白容纳元素增长，仍保持单行操作与两到六行自动提示词高度。
