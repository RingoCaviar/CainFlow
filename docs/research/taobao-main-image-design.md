# 淘宝／天猫商品主图与白底素材

核对日期：2026-11-18。本地 Issue：`ecommerce-image-set#026`。

用户反馈淘宝商品主图过于单一，且标题和卖点被清空。原预设与京东、拼多多共用禁止文案的用途描述，`allowCopy: false` 又使模型返回的标题、正文在方案归一化时被移除，最终生图请求也会禁止添加文字。

## 一手资料与适用范围

- [淘宝客商品详情 API](https://developer.alibaba.com/docs/api.htm?apiId=64759)：分别提供商品主图 `pict_url` 与白底图 `white_image`，说明两类素材有独立用途。
- [主图编辑应用接入官方合图能力公告](https://developer.alibaba.com/support/announcementDetail.htm?id=25574)（2021-05-25）：涉及天猫商品主图的价格合成、字体颜色及打标，并要求优惠表达准确。这是特定主图编辑业务及活动的公告，可证明主图存在图文设计用途，不能用作所有类目的现行通用规则。
- [天猫大家电第二张主图标准](https://g.alicdn.com/mui/zebra-seller-tmallqc-static/3.2.23/other/tian_mao_da_jia_dian_di_er_zhang_zhu_tu.html)：此特定类目及图位要求白底、无说明文字与营销口号。页面附有 2015 版模板，仅用于说明规则按类目、图位区分，发布时应核对商家后台现行要求。

这些资料支持区分商品主图和白底素材。未找到要求所有淘宝首图必须带标题、卖点或统一文字占比的现行全类目官方规范。

## 本次预设调整

淘宝／天猫的商品主图默认规划精致的商业主视觉，结合商品名称或类目安排简短标题，以可核实卖点安排辅助说明；背景、配色、光影、商品位置和文字层级共同构图。这是针对用户反馈的产品设计选择。文案继续可编辑、可清空，生图使用用户最终确认的文字，保留原有商品、包装和商标。

独立的白底素材仍只展示商品，不添加标题、卖点、道具和边框。其他平台预设保持既有行为，抖音与亚马逊的首图仍沿用参考原图。已保存的旧方案不自动重写，重新规划后使用新的淘宝主图预设。

预设、方案归一化和生图提示词位于共享的 `commerce-image-set-plan.js`，内置 Agent、Canvas MCP 与节点界面沿用同一执行链路；本次不增加操作、参数或公开投影字段。
