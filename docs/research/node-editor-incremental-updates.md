# Blender 和 ComfyUI 的连线更新与端口命中

2026-11-15 核对 Blender 和 ComfyUI 前端官方仓库的 `main`，并参考 React Flow 的逐边渲染。上游源码链接均固定到提交。

## 拖动节点时更新哪些连线

- **Blender** 为每个 socket 缓存直接相连的边和 socket，并缓存拓扑顺序。拓扑缓存失效后会扫描全树重建。拖动节点会写入本次变换的节点位置，普通绘制仍按未选中和已选中两遍遍历全部边，以当前 socket 坐标计算贝塞尔曲线，并在绘制前做视区裁剪。[邻接缓存](https://github.com/blender/blender/blob/4223993fe4f6b45cd305ac1f15c5fb3fa5383eb8/source/blender/blenkernel/intern/node_runtime.cc#L118-L156)、[拓扑缓存](https://github.com/blender/blender/blob/4223993fe4f6b45cd305ac1f15c5fb3fa5383eb8/source/blender/blenkernel/intern/node_runtime.cc#L544-L573)、[移动节点](https://github.com/blender/blender/blob/4223993fe4f6b45cd305ac1f15c5fb3fa5383eb8/source/blender/editors/transform/transform_convert_node.cc#L336-L366)、[遍历连线](https://github.com/blender/blender/blob/4223993fe4f6b45cd305ac1f15c5fb3fa5383eb8/source/blender/editors/space_node/node_draw.cc#L4736-L4753)、[计算曲线和裁剪范围](https://github.com/blender/blender/blob/4223993fe4f6b45cd305ac1f15c5fb3fa5383eb8/source/blender/editors/space_node/drawnode.cc#L1846-L1863)
- **ComfyUI** 的 `linkStore` 增删边时维护输入和输出端口索引，`nodeLinkIds` 只查询该节点自己的端口就能拿到相连的边。传统 Canvas 拖动节点会将两层标记为待重绘，Vue Nodes 的布局变化也会触发同样的标记。共用的 `drawConnections` 每次绘制会按目标节点分组当前图的拓扑，遍历连线和计算端点，再裁剪视区外的线段。[索引维护](https://github.com/Comfy-Org/ComfyUI_frontend/blob/4e44947c7c1e4e1bfd7206b01775af8c23fc967b/src/stores/linkStore.ts#L122-L172)、[节点相连的边](https://github.com/Comfy-Org/ComfyUI_frontend/blob/4e44947c7c1e4e1bfd7206b01775af8c23fc967b/src/lib/litegraph/src/node/slotLinks.ts#L60-L84)、[传统拖动](https://github.com/Comfy-Org/ComfyUI_frontend/blob/4e44947c7c1e4e1bfd7206b01775af8c23fc967b/src/lib/litegraph/src/LGraphCanvas.ts#L3922-L3938)、[布局通知](https://github.com/Comfy-Org/ComfyUI_frontend/blob/4e44947c7c1e4e1bfd7206b01775af8c23fc967b/src/renderer/core/canvas/litegraph/notifyLayoutChanges.ts#L21-L26)、[遍历和计算端点](https://github.com/Comfy-Org/ComfyUI_frontend/blob/4e44947c7c1e4e1bfd7206b01775af8c23fc967b/src/lib/litegraph/src/LGraphCanvas.ts#L6263-L6302)、[线段裁剪](https://github.com/Comfy-Org/ComfyUI_frontend/blob/4e44947c7c1e4e1bfd7206b01775af8c23fc967b/src/lib/litegraph/src/LGraphCanvas.ts#L6553-L6562)

- **React Flow** 的每条 SVG 边独立读取两端节点，订阅端点坐标、方向和层叠顺序。订阅结果经浅比较相同就不会触发该边组件重渲染。可见边列表仍会遍历边集合。[单边订阅](https://github.com/xyflow/xyflow/blob/1bc405cd113618c17fd181b931a9fe573bec9fee/packages/react/src/components/EdgeWrapper/index.tsx#L63-L108)、[可见边列表](https://github.com/xyflow/xyflow/blob/1bc405cd113618c17fd181b931a9fe573bec9fee/packages/react/src/hooks/useVisibleEdgeIds.ts#L15-L50)

## 拖动连线时怎样找端口并落线

- **Blender** 在鼠标移动时按反向绘制顺序扫描节点和对应方向的 socket，用随缩放变化的距离阈值找最近且未被遮挡的候选。确认时使用已悬停的候选，处理重复边和端口容量，调用节点的插边回调。图更新还能把已加到图里的类型不兼容或造成环的边标为无效。[移动与确认](https://github.com/blender/blender/blob/4223993fe4f6b45cd305ac1f15c5fb3fa5383eb8/source/blender/editors/space_node/node_relationships.cc#L1582-L1622)、[端口命中](https://github.com/blender/blender/blob/4223993fe4f6b45cd305ac1f15c5fb3fa5383eb8/source/blender/editors/space_node/node_edit.cc#L793-L882)、[提交处理](https://github.com/blender/blender/blob/4223993fe4f6b45cd305ac1f15c5fb3fa5383eb8/source/blender/editors/space_node/node_relationships.cc#L1272-L1367)、[有效性检查](https://github.com/blender/blender/blob/4223993fe4f6b45cd305ac1f15c5fb3fa5383eb8/source/blender/blenkernel/intern/node_tree_update.cc#L1633-L1675)
- **ComfyUI 传统 Canvas** 在预览时从可见节点逆序找命中的节点，再测该节点的端口矩形，或者在该节点内按类型挑端口。松手时用最终坐标重新命中并调用连线兼容性检查。[预览入口](https://github.com/Comfy-Org/ComfyUI_frontend/blob/4e44947c7c1e4e1bfd7206b01775af8c23fc967b/src/lib/litegraph/src/LGraphCanvas.ts#L3687-L3753)、[节点内类型匹配](https://github.com/Comfy-Org/ComfyUI_frontend/blob/4e44947c7c1e4e1bfd7206b01775af8c23fc967b/src/lib/litegraph/src/LGraphCanvas.ts#L3814-L3858)、[逆序查节点](https://github.com/Comfy-Org/ComfyUI_frontend/blob/4e44947c7c1e4e1bfd7206b01775af8c23fc967b/src/lib/litegraph/src/LGraph.ts#L1623-L1635)、[端口矩形](https://github.com/Comfy-Org/ComfyUI_frontend/blob/4e44947c7c1e4e1bfd7206b01775af8c23fc967b/src/lib/litegraph/src/canvas/measureSlots.ts#L10-L45)、[松手命中](https://github.com/Comfy-Org/ComfyUI_frontend/blob/4e44947c7c1e4e1bfd7206b01775af8c23fc967b/src/lib/litegraph/src/canvas/LinkConnector.ts#L704-L734)、[提交检查](https://github.com/Comfy-Org/ComfyUI_frontend/blob/4e44947c7c1e4e1bfd7206b01775af8c23fc967b/src/lib/litegraph/src/canvas/LinkConnector.ts#L1033-L1073)
- **ComfyUI Vue Nodes** 通过浏览器的 `elementFromPoint` 命中 DOM，解析当前端口或节点，再计算兼容候选。松手时重新读取最终坐标的 DOM 命中，结合已吸附的候选决定目标，提交前检查每条待接边。[DOM 命中](https://github.com/Comfy-Org/ComfyUI_frontend/blob/4e44947c7c1e4e1bfd7206b01775af8c23fc967b/src/renderer/extensions/vueNodes/composables/useSlotLinkInteraction.ts#L114-L131)、[拖动候选](https://github.com/Comfy-Org/ComfyUI_frontend/blob/4e44947c7c1e4e1bfd7206b01775af8c23fc967b/src/renderer/extensions/vueNodes/composables/useSlotLinkInteraction.ts#L405-L475)、[松手](https://github.com/Comfy-Org/ComfyUI_frontend/blob/4e44947c7c1e4e1bfd7206b01775af8c23fc967b/src/renderer/extensions/vueNodes/composables/useSlotLinkInteraction.ts#L619-L658)、[提交检查](https://github.com/Comfy-Org/ComfyUI_frontend/blob/4e44947c7c1e4e1bfd7206b01775af8c23fc967b/src/renderer/extensions/vueNodes/composables/useSlotLinkInteraction.ts#L250-L283)
- **ComfyUI 的四叉树用于查线段和转接点。** 线段查询先用包围盒取候选，再以 `isPointInStroke` 精确命中。需要找出所有重叠线段时，调用方仍遍历已绘制的路径。上述普通端口拖拽分别使用节点内矩形和 DOM 命中。[四叉树](https://github.com/Comfy-Org/ComfyUI_frontend/blob/4e44947c7c1e4e1bfd7206b01775af8c23fc967b/src/renderer/core/spatial/SpatialIndex.ts#L24-L40)、[候选与精查](https://github.com/Comfy-Org/ComfyUI_frontend/blob/4e44947c7c1e4e1bfd7206b01775af8c23fc967b/src/renderer/core/layout/store/layoutStore.ts#L637-L696)、[实际调用](https://github.com/Comfy-Org/ComfyUI_frontend/blob/4e44947c7c1e4e1bfd7206b01775af8c23fc967b/src/lib/litegraph/src/canvas/hitTesting.ts#L12-L57)

## 对照 CainFlow

CainFlow 已用节点到连线的邻接索引缩小 SVG 路径更新范围，并复用屏幕坐标网格查询鼠标附近的兼容端口。松手时会重新测量目标并校验连线。SVG 增量路径仍有全图连接签名扫描和可能的走线缓存重建，Canvas 路径会走全量刷新。端口布局缓存失效时，网格会重测全部端口，反馈也可能重新遍历端口。复用邻接、先缩小候选再精查，以及松手校验都有上游先例。进一步缩小全图工作实际能省多少，应以 CainFlow 的 WebView2 拖动测量为准。[SVG 更新](../../js/canvas/connections.js#L1571-L1615)、[连接签名](../../js/canvas/connections.js#L145-L148)、[走线计算](../../js/canvas/connections.js#L388-L393)、[端口网格与松手重测](../../js/canvas/connections.js#L2015-L2091)、[反馈](../../js/canvas/connections.js#L2120-L2150)、[提交](../../js/canvas/connections.js#L2304-L2316)
