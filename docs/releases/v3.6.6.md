## 🚀 3.6.6 更新内容

### ✨ Prompt Agent
- 新增面向图片生成节点的 Prompt Agent：结合当前工作流上下文生成提示词方案，支持先应用方案或应用后生成。
- 对话与创作上下文跟随工作流保存和恢复；切换工作流时保持隔离。
- 优化侧边面板布局和模型选择菜单；没有可用对话模型时显示轻提示与“点击添加模型”入口。

### 🔌 模型与协议
- 扩展声明式协议配置的编辑、验证与恢复能力。
- 修复 OpenAI 官方 API 地址获取模型列表时因旧供应商类型而请求 Google 路径、返回 404 的问题；基础地址和完整模型列表地址均可使用。

### 🧹 缓存与界面
- 清理无引用图片后同步更新缓存状态；手动清理遇到受保护或回收失败的媒体时，不再误报全部清理成功。
- 移除左上角重复的画布按钮，并修正 Agent 面板与顶部菜单栏的重叠。

## 💡 升级说明

关闭旧版后启动新版即可，无需手动迁移。原有供应商配置、工作流及媒体文件会继续保留。
