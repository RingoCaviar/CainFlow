## 🚀 4.1.1 更新内容

### 电商套图

- 每个图位可生成 1 至 8 张候选图。可并排对比、全屏切换，采用候选图时同步恢复对应的文案和提示词。
- 可从画布或历史选择风格参考图，并分配给整套或指定图位。整套美术风格支持自动规划、手动调整或复用「画面风格」节点。
- 缩减图位时沿用已确认的方案，重做时保留定稿，缺失的图位可补齐。运行前会提示需要补充的内容。
- 淘宝和天猫的主图按已确认的卖点编排标题和文案。亚马逊新方案默认生成白底精修主图，已有方案保留原来的主图设置。各图位可按用途选择参考图中可核实的商品视角。

### 画布与工作流

- 修复 Chrome 中拖动画布的顿挫，并在松手时按最终位置保存视口。
- 优化窄窗口中的画布导航及运行范围操作。批量生成结果可在原图预览中连续切换。

### 内置 Agent

- 每个工作流保留自己的对话草稿和附件。切换工作流后，已发出的请求可继续生成回复。
- 可复制和重新发送用户消息，并使用原始输入重试失败的回复。
- 改进画布方案预览、附件选择、键盘操作和窄窗口布局。升级后仍可继续应用旧版保存的电商套图方案。

## 💡 升级说明

关闭旧版并更新程序后重新启动，无需手动迁移。
