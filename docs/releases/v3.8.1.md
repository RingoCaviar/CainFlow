## 🚀 3.8.1 更新内容

### 🎛️ Agent 模型与供应商

- 对话、生图、专用搜索及方案步骤直接选择“模型 · 供应商”，移除“按优先级”选项。
- 选择随工作流和模型保存；供应商失效时明确提示，不自动回退其他渠道。
- Agent 对话、搜索、整理及上下文压缩请求纳入统计，生图沿用节点统计，避免重复计数。

### 📐 生图尺寸与比例

- Agent 底部新增尺寸设置浮层，统一分辨率、比例及自定义宽高选项，适配七套主题。
- 修复修改比例时提示“不支持参数 aspect”的问题；自动分辨率不允许指定比例时，保留草稿并询问所需分辨率，不擅自选择 1K。
- 支持点击档位或回复分辨率更新原方案，确认后才应用或生成；设置按工作流和模型保存。
- 完整校验目标尺寸组合，保留已生成结果的尺寸记录，修复重复应用可能影响整批撤销的问题。

### 🎨 菜单细节

- 右键“搜索节点”统一为带搜索图标的平面菜单行，修复原生按钮底色与边框不协调的问题。

## 💡 升级说明

无需手动迁移工作流。此前没有明确指定 Agent 供应商的设置会显示“请选择供应商”，请在模型菜单中手动选择后使用；已有明确选择保留。尺寸设置默认跟随方案，不自动覆盖旧方案。建议升级前备份工作流。
