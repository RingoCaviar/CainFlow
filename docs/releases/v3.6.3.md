## 🚀 3.6.3 更新内容

### 🐛 图片导入稳定性
- 🖼️ 修复图片导入节点在工作流运行后错误恢复为旧图片的问题。
- 🔒 当节点已有持久化 Media asset reference 时，运行时优先读取当前 Media asset，不再被过期 inline 缓存覆盖。
- ✅ 增加图片导入运行时回归测试，覆盖重新导入后执行工作流的场景。

## 💡 升级说明

关闭旧版后启动新版，无需手动迁移。已有工作流会继续使用其持久化 Media asset reference。
