## 🚀 4.0.9 更新内容

### 电商套图

- 可定稿已完成的图位。重做整套时会沿用定稿图片及其输出位置，解锁后可继续编辑或重新生成。
- 每个生图图位可一次生成 1 至 4 张，默认 1 张。候选窗口可以并排比较图片、文案和提示词，采用候选时会恢复该版本的文案和提示词。套图输出和导出使用当前选定的图片。
- 在面板中取消生成时，会停止剩余请求，并保留原来选定的成图和本轮已生成的候选。
- 主副图和详情图可以分别追加场景，单独规划和生成。多余的场景可在套图任务结束后移除。修改图位文案或提示词后，仍可查看标为「上一版」的成图。
- 更换或重排商品参考图后会提示重新规划。可以单独预览或导出上次套图。
- 支持预览并打包下载整套、主副图或详情图。ZIP 内保留图片原始格式和图位顺序，导出前可看到缺图和上一版成图。

### 文本节点

- 优化文本节点编辑、阅读与键盘操作；编辑时点击卡片内部保持文本编辑状态，改善文本选择和交互反馈。

### 画布与 Agent

- 打开大工作流、批量导入或生成图片时，图片预览分批加载，优先显示视口内的图片，减少画布卡顿。
- 切换生图批次中的图片时，预览加载期间保留已有比例，避免卡片高度短暂跳动。
- 内置 Agent 和 Canvas MCP 新建独立节点时会优先放在当前可见区域附近。与现有节点连线的新节点会靠近对应的上游或下游节点。

## 💡 升级说明

关闭旧版并更新程序后重新启动，无需手动迁移。旧套图的参考图版本无法核实时，打开套图面板按提示重新规划即可。
