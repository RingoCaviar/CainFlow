## 🚀 3.6.10 更新内容

### 🖼️ Agent 生图与结果保存
- 对话模型与生图模型独立设置，生图模型由用户手动选择；先查看方案，点击生成时自动创建或复用生图节点。
- 每次生成保留独立图片记录，重启、后续生成或删除画布节点后仍可查看已保存的历史结果。
- Agent 图片使用与保存节点、预览节点一致的全屏预览，修复拖动后误关闭的问题。
- 图片、视频生成节点没有启用的下游目标时，自动补充保存节点并参与本次运行；禁用的下游节点不再阻止自动保存。

### 📎 图片导入与参考图选择
- 支持在 Agent 中粘贴、拖入及上传图片，自动创建图片导入节点并引用。
- 参考图选择增加场景／历史页签、搜索、多选编号、分批加载和独立预览；重复选择历史图片可复用未修改的导入节点。
- 导入失败支持重试，切换工作流或清空会话后，晚到的导入结果不会恢复已取消的引用。

### ✨ 更紧凑的 Agent 面板
- 模型设置集中到输入框上方，移除顶部标题栏；支持左侧拖动调整宽度，并跨工作流、重启保存宽度偏好。
- 阅读较早消息时提供回到底部按钮；优化模型下拉菜单、主题区分度及参考图加号的居中效果。
- 打开 Agent 不再强制展开顶部工具栏；单击画布空白处可收起面板，保留草稿及运行状态。
- 面板底部贴齐工作区，画布导航移到面板左侧，通知自动避让面板。

## 💡 升级说明

无需手动迁移，直接升级即可。生图前请在 Agent 中手动选择生图模型；旧会话不会自动选择模型。旧存档没有记录的历史生成批次不会凭空恢复。已有面板宽度在没有全局偏好时自动迁移一次。
