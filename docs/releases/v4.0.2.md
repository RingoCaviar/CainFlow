## 🚀 4.0.2 更新内容

### 提示词引用参考图

- 在支持图片输入的节点或 Agent 的提示词中输入 `@`，即可按缩略图和来源查找上游参考图、当前画布图片或目录历史。节点引用保留原有连线，Agent 选中的图片随本轮消息发送。
- 已插入的图片引用带有主题色标记，悬停可看缩略图，点击可更换这一处引用。提示词支持原生撤销和重做。

### 生图进度

- 生成状态收成底栏上方的一行。单张失败时，可以直接查看原因并重试。
- 多张生成默认显示完成数及异常张数。展开明细后，可以查看每张图片的状态、预览已完成的图片，或单独重试失败的图片。

## 💡 升级说明

无需迁移数据。关闭旧版并更新程序后重新启动即可。
