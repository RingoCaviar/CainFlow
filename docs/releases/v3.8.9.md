## 🚀 3.8.9 更新内容

### 🎨 生图节点与创作助手

- 调整生图节点的内容顺序，将提示词、参考图和常用参数集中展示；高级参数按组展开，保留原有参数、节点尺寸和编辑区域高度。
- 参考图改为紧凑缩略图排列，多图时在节点内部滚动；保留完整批次、原图预览、来源定位、排序和断开操作。
- 增加从生图节点进入助手优化的入口，统一节点、助手结果与历史图片的原图操作，减少重复操作。
- 节点就近显示执行状态，移除底部重复的运行和日志按钮，相关操作保留在右键菜单。

### 🖼️ Agent 参考图处理

- 修复从节点打开助手或使用 @ 引用节点时，取错目标或未正确携带参考原图的问题。
- 优化提示词、应用方案和重新生成均遵循已有参考来源、完整批次和明确顺序，避免因助手漏列图片而擅自断开连接。
- 重试前检查已完成上游的原图是否变化；需要重新确认的方案会明确提示，避免静默使用旧图或丢失参考图。

### 🔗 画布连线与节点编辑

- 修复从输入、输出端口拖线后新建节点未自动连线的问题，兼容生图、对话、视频和动态合并端口。
- 重连取消或失败时保留原连接；端口失效或输入已满时，在创建前给出提示。
- 修复复制、粘贴和克隆时遗漏参考来源、媒体批次或动态端口连接的问题，粘贴可作为一次完整操作撤销和重做。
- 保留连线删除按原参考位置接回上游，容量不足时保持原图；跨工作流粘贴不误接同 ID 节点，运行中关联连接受到保护。
- 剪贴板与撤销记录分别临时保护本地图片和视频，减少复制后删除原节点导致媒体无法恢复的问题。

### 🛠️ 运行反馈

- 生图错误支持完整换行和长文本折行，避免红色提示被截断。
- 新一轮进入待运行、运行中或自动重试时立即清除上一轮报错；再次失败显示本轮错误，历史日志和未参与运行节点的错误保留。

## 💡 升级说明

无需手动迁移，现有工作流和模型配置可继续使用。升级前保存当前工作流，更新后重新启动应用即可。
