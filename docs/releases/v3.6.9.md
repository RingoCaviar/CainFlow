## 🚀 3.6.9 更新内容

### 🤖 Agent 意图与连续创作
- 改进普通讨论、新建画面、编辑图片和连续修改方案的判断，减少不必要的追问，并保留用户明确指定的主体、文字与限制。
- 后续修改可沿用尚未应用的完整最新方案，保留参数、负面提示词和参考图角色，避免退回节点中的旧提示词。

### 🖼️ 场景参考图
- Agent 输入框的加号可列出当前场景图片导入节点中的图片，支持多选、取消和原图读取。
- 参考图按勾选顺序显示序号，发送后和历史消息中保留编号，方便使用“第 1 张”“第 2 张”继续描述需求。

### 💬 上下文命令
- 输入 `/` 打开命令菜单，支持键盘和点击选择；`/clear` 清空当前场景的 Agent 聊天、摘要、方案和参考图。
- `/compact` 使用当前对话模型整理上下文摘要，保留关键要求、最新完整方案和参考图对应关系；历史聊天仍可查看。
- 压缩失败、取消或切换场景时保留原上下文，迟到回复不会写入新的对话。

### ⚡ 生成反馈与界面
- 修复点击“应用并生成”后，节点仍在工作而 Agent 提前提示生成失败的问题；现在等待本次运行完成，再显示结果或具体错误。
- 缓存面板新增 Agent 缓存卡片，显示当前及已打开场景的估算占用、消息、参考图、归档和摘要数量。
- Agent 按钮增加主题协调的渐变描边、悬停光晕和展开高光，更容易与其他入口区分。

## 💡 升级说明

关闭旧版后启动新版即可，无需手动迁移。已有工作流的 Agent 对话保持兼容；上下文压缩需要配置可用的对话模型，并会调用该模型。压缩保留聊天归档，清空当前场景的 Agent 数据可使用 `/clear`。
