## 🚀 4.1.6 更新内容

### GPT Image 图像输出与编辑

- GPT Image 2.6 Sunburst 和 Flare 支持生成和编辑动画 GIF，可设置帧数与帧时长。纯提示词生成支持 SVG，保存和下载时保留原始文件格式。
- GPT Image 2.5 和 2.6 支持用透明 PNG 标注图层引导编辑。画布、Prompt Agent 和 Canvas MCP 共用图像参数与输入校验。

### 画布与智能对话

- 智能对话节点采用紧凑卡片。单击回复可选中节点，拖动回复可移动节点，打开「放大查看」即可选取并复制文字。
- 优化 Prompt Agent 面板中消息、代码块和画布方案的排版。
- 连续平移大画布时，性能保护状态切换期间网格会继续跟随节点和连线。结束平移后会检查连线对齐。

### 应用更新

- 更新窗口随屏幕高度调整，可滚动查看完整说明，底部操作按钮保持可见。
- 设置页打开时，代理测试延迟和后台下载进度仍然可见。

## 💡 升级说明

已有工作流无需手动迁移。旧工作流的遮罩编辑继续使用原有配置。官方 GIF 接口需要项目具备预览权限。
