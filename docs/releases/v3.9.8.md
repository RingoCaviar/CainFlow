## 🚀 3.9.8 更新内容

### 画布与工作流

- 缩到最低 10% 时，视口内的节点仍显示完整内容。平移和缩放时减少离屏节点的尺寸读取和重复刷新，降低大型画布的布局开销。
- 打开或重载工作流时显示画布加载状态。顶栏显示当前工作流的启动、运行和停止状态，点击停止只影响当前工作流。
- 修复预览断开连线后被晚到的图片读取覆盖状态的问题，断线后仍可查看已保留的结果。

### 节点与设置

- 简化图片卡片和节点参数浮层。单击图片打开参数，拖动图片移动节点，双击查看原图。参数浮层随画布移动，点击浮层或 Agent 面板即可切到前面。
- 生图提示词上方直接展示参考图，可按来源排序、定位或断开。尺寸、模型、更多设置、次数和生成集中在底栏。
- 常规设置按用途分类，供应商和模型卡片可直接改名。优化窄窗口下的表单布局、顶栏自动收起和主题菜单交互。

### Agent

- 改进画布方案预览、重复运行和失败后的重试。可以在已有批次运行时发起独立批次，重试只执行仍需处理的步骤。
- 优化 Agent 面板宽度、消息操作和结果图片拖入画布的体验，修复清空上下文后旧内容未立即消失的问题。
- 修复重做遇到工作流保存版本冲突后，媒体引用未恢复并导致 Agent 重试保存失败的问题。

## 💡 升级说明

无需额外数据迁移。关闭旧版并更新程序后重新启动即可。旧工作流中的折叠节点会在打开时展开。
