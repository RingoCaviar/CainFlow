## 🚀 3.7.9 更新内容

### 🖼️ Agent 参考图与节点布局

- 独立文生图不再因为历史候选或旧连线而自动使用参考图，阻止未确认的图片导入步骤。
- 仅调整提示词时保留上一版方案素材，继续编辑成品时沿用最新结果选择规则。
- 参考图导入在应用方案时进行，方案卡显示实际输入；独立生成重用节点时显式清除旧参考连线。
- 自动保存节点与 Agent 新建节点采用二维就近避让，避免被其他行的节点推到很远的位置，保留已有节点的位置。

### 🎨 Agent 对话与菜单

- 统一联网方式、对话模型、生图模型和步骤模型的菜单样式、主题配色、键盘操作及父子浮层行为。
- 简化对话层级，折叠变更详情与步骤参数，整理底部输入与操作区域。
- 普通主题下 Agent 面板使用不透明背景，玻璃浅色与玻璃深色主题保留透明效果。
- Agent 内按钮采用平面风格，移除发光、渐变、浮雕阴影和按压缩放，保留悬停与键盘焦点提示。

### 📝 换行与变更清单

- 正文正确显示换行、段落、列表、强调和代码，兼容模型重复转义的换行符；代码、路径及用户原文保持原样。
- 修复变更清单将真实换行显示为字面 `\n` 的问题，多行字段按“修改前／修改后”分段展示。

## 💡 升级说明

无需手动迁移或额外配置，直接升级即可。保留先看方案再执行、手动选择生图模型的流程；升级前建议备份自己的工作流。历史结果不会因本次界面调整而删除。
