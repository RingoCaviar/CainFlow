## 🚀 3.8.4 更新内容

### 💾 关闭与保存

- 修复已保存的工作流在关闭时被重复写入、并可能误报保存失败的问题；有未保存改动的工作流仍会在关闭前保存。
- 保存确实失败时仅重试失败的工作流，并显示应用内对话框及失败工作流名称，方便返回软件处理。
