## 🚀 3.7.7 更新内容

### 🧩 Agent 全画布理解与多步骤建图

- Agent 可读取画布结构，结合 @节点 引用理解操作对象，展示多步骤方案和节点、参数、连线的变更清单。
- 支持图片导入、生图、尺寸调整、拼接、预览、对比、保存及静态文本组成的流程，保留先看方案再执行、手动选择模型。
- 方案批量应用形成一个撤销步骤；执行失败保留成功结果，可重试未完成步骤，重做不会自动再次生成。

### 🔎 搜索设置与面板协调

- 修复搜索能力设置重启丢失，保留自动压缩阈值及导入配置中的独立 Responses 地址。
- 搜索能力不足时提供专用搜索模型与 Provider 配置入口，明确显示不可用原因，不自动切换模型。
- 统一主面板互斥、临时菜单及模态窗口层级，改善键盘关闭和焦点恢复。

### 🧹 撤销图片保护与退出清理

- 有效撤销、重做记录临时保护图片，手动清理缓存后仍可恢复；记录淘汰或正常退出时释放保护。
- 退出前等待保存和媒体提交，再回收无其他引用的图片；其他工作流、Agent 历史及共享媒体继续保留。
- 异常退出遗留保护在后续启动恢复后处理；清理延后或失败保留待处理状态，缓存面板显示撤销保护与待清理情况。

## 💡 升级说明

无需手动迁移或额外配置。撤销记录仍不跨重启保留，正常退出会先完成保存；保存失败可重试或取消退出。受其他有效引用保护的图片不会被退出清理删除。
