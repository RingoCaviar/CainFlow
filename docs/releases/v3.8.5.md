## 🚀 3.8.5 更新内容

### 🪟 桌面窗口

- 启动时恢复上次关闭前的窗口位置和大小。显示器布局变化导致旧位置不可见时，窗口会由系统重新定位。

### ⚙️ 设置

- 在设置中新增或修改模型后，打开 Agent 上下文压缩模型菜单即可看到最新可用模型，无需关闭再打开设置。

### 🖼️ 参考图介绍

- 图片节点与 Agent 参考图的全屏预览右上角新增“介绍”按钮。可在弹窗中输入或修改图片介绍，并通过确认或取消完成操作。
- 介绍随工作流或 Agent 对话保存。后续生图、对话与视频请求会按参考图顺序带上介绍，Agent 也会在图片清单中提供介绍。

## 💡 升级说明

无需手动迁移或额外操作。已有参考图默认没有介绍，可按需在预览中补充。
