## 🚀 4.1.5 更新内容

### Canvas MCP

- 可以列出已保存的工作流，并按工作流 ID 读取、编辑、撤销和运行。以 `--headless` 启动本地服务后，关闭所有编辑器窗口仍可使用这些功能。
- 编辑和运行会检查读取时的保存版本，避免覆盖较新的改动。重新打开工作流时会载入最新保存版本，尚未保存的编辑器草稿会保留。
- 可在后台运行文本、图片导入、通用输出、智能对话、生图和视频生成等节点，并查询进度和结果。成功保存的节点结果会写回工作流，生成的图片和视频按设置归档。可运行类型由 `read_canvas` 的 `runnableTypes` 列出。

## 💡 升级说明

关闭旧版并更新程序后重新启动，已保存的工作流无需手动迁移。没有工作流 ID 的旧文件在编辑器中打开并保存一次后，即可通过 MCP 找到。

使用 Canvas MCP 的机器需要 Node.js 22 或更新版本。桌面版用户请在「画布 MCP」设置中重新复制客户端配置并重载客户端。直接调用 MCP 工具的集成请改用 `workflowId` 和读取时的 `revision`，批量生图还需指定 `sourceNodeIds`。
