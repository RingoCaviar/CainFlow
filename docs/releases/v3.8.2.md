## 🚀 3.8.2 更新内容

### 💬 Agent 对话与上下文

- 修复桌面重启后对话模型选择丢失：改为磁盘保存，兼容当前浏览器可读取的旧选择。

- 发送有效消息后自动回到最新位置，继续跟随回复和图片加载；主动向上阅读时停止跟随。
- 自动压缩显示批次和等待时间，增加超时与取消保护，避免长期停留在压缩状态。
- 减少同一轮重复压缩，并补充上下文圆环的阈值说明。

### 🖼️ 参考图与创作参数

- 修复参考图参与生成但画布连线不可见的问题，统一真实参考图端口及多图顺序。
- 执行前核对参考图来源和资产，阻止失效或与已应用方案不一致的输入。
- 同一创作任务保留明确指定的比例、分辨率等参数，后续修改背景不再因模型漏写而丢失设置。
- 任务参数随工作流保存，压缩后保留；明确开始新任务或清空会话时重置，步骤专属设置不会扩散到其他步骤。

## 💡 升级说明

无需手动迁移。若旧对话模型选择已随浏览器来源变化而丢失，请重新选择一次，之后会保存到磁盘。旧会话不会从任意节点推断任务参数；请明确告知 Agent 本次创作要求。继续保留手动选择模型、供应商和先看方案再执行的流程。建议升级前备份工作流。
