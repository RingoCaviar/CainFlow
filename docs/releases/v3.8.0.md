## 🚀 3.8.0 更新内容

### 🧠 对话与生图思考设置

- 模型设置新增思考参数兼容方式、默认设置及 Provider 独立兼容模板，按模型能力提供等级、Token 预算或开关。
- Agent 对话与生图模型旁新增紧凑思考设置入口；画布对话、生图节点和多步骤方案支持独立覆盖。
- 设置随模型配置与工作流保存，切换模型保留各自选择；清空、压缩会话保留 Agent 设置。
- 接入 OpenAI 对话、Responses 搜索、Gemini、DeepSeek 和 Qwen 已登记参数，保留 TTAPI 旧参数；OpenAI 生图画质仍为独立设置。
- 未知中转默认不额外发送思考字段，参数失效或冲突时明确提示，不自动降档或换模型。
- 修复执行前重置导致思考覆盖丢失的问题，过滤 Gemini 思考过程中的中间文字及图片。

### 🏷️ 模型供应商显示

- Agent 对话、生图、专用搜索及方案步骤模型菜单统一显示供应商，便于区分同名模型和不同渠道。
- 保留手动选模、先看方案再执行和紧凑平面菜单风格。

## 💡 升级说明

无需手动迁移。旧配置保持原有请求行为，默认由接口控制思考；需要调整时在模型设置中配置。中转接口请按供应商文档选择兼容模板，模板不会让不支持的模型获得思考能力。建议升级前备份工作流。
