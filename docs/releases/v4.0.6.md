## 🚀 4.0.6 更新内容

### 电商套图

- 新增可编辑的产品信息，包括名称、核心卖点、适用人群、使用场景和规格资料。「分析产品」可根据参考图补全空白字段，生成方案时也会自动分析。手填内容优先，资料随工作流保存。
- 可指定图中文字语言，适用于整套方案及单张图位重写。切换语言后需要重新规划，上一套成图仍可查看。原有工作流默认沿用自动语言设置。

### Agent 与 Canvas MCP

- 支持将历史目录中的原图导入当前画布，以及将提示词库的普通提示词或系统提示词应用到指定节点。
- 可就地重命名、移动、启用或停用节点，建立连线或断开指定连线，并从当前画布运行、停止、撤销或重做操作。内置 Agent 会先展示就地编辑方案，支持复用的方案也可选择创建副本。
- 两个入口均可读取和编辑电商套图的产品信息及图中文字语言。

### 工作区与图片工具

- 统一设置、节点和媒体工具中的下拉框、开关及键盘焦点样式。调整历史与执行日志抽屉、裁切和画笔布局，改善窄窗口下的操作空间与阅读体验。
- 多行输入框从两行起步，自动伸缩至六行，内容更多时可在框内滚动。手动拖高后可继续编辑，自动回填时会保留手动高度。

## 💡 升级说明

无需迁移数据。关闭旧版并更新程序后重新启动即可。已连接外部 Canvas MCP 客户端的用户，可重启客户端以重新加载工具列表和参数。

如果升级前保存的 Agent 画布方案提示相关内容已变化，可根据当前画布重新生成方案，再确认应用或运行。
