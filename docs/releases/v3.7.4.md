## 🚀 3.7.4 更新内容

### 🌐 Agent 联网搜索与搜图
- Agent 底部新增“联网”入口，可切换自动／关闭，并手动设置专用搜索模型。普通聊天不额外搜索；查证、最新资料和搜图需求可先检索，再由原对话模型整理回复或方案。
- 支持 Gemini 原生网页搜索，以及 OpenAI Responses 网页和图片搜索。优先使用具备对应能力的当前对话模型，否则使用所选专用模型；配置缺失或失效时提示，不自动切换其他模型。
- 回复支持可点击的来源引用与来源列表，搜索结果随工作流会话保存，重启和压缩后仍可查看。

### 🖼️ 搜索图片作为参考图
- 搜图结果以图片卡片展示，支持共享全屏预览和“加入参考图”。预览不创建节点；手动选用后导入本地原图，自动创建图片导入节点并加入待发送参考图。
- 重复选用未修改的图片会复用导入节点，已导入图片可继续离线使用；原图读取失败时提示错误，不以缩略图替代。
- 网络图片读取增加公共地址、重定向、超时、大小和格式检查。取消、清空或切换工作流后，晚到结果不会恢复已取消的引用或写入其他工作流。

### 🧭 上下文进度与交互修复
- 修复清空上下文后圆环仍显示使用进度的问题：空会话显示 0%，并单独说明下次请求的固定开销；自动压缩仍按完整请求的 Token 阈值触发。
- 搜索内容计入实际对话上下文，专用搜索模型的累计用量不混入进度。压缩保留相关结论及来源对应关系。
- 优化窄面板的联网菜单布局，修复搜索取消或失败后仍显示“正在搜索”的问题。

## 💡 升级说明

无需手动迁移，直接升级即可。旧工作流默认允许按需联网，专用搜索模型保持未指定。

使用 OpenAI 兼容接口时，请在模型设置中明确启用“Agent 搜索能力”，并确认服务商支持 Responses 搜索；Provider 关闭地址自动补全时，还需填写独立 Responses 地址。旧 Google 对话配置默认尝试原生网页搜索，搜图需要支持图片搜索的 OpenAI Responses 模型。

继续保留手动选择生图模型、先看方案再点击生成的流程。
