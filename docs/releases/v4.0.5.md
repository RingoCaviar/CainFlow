## 🚀 4.0.5 更新内容

### 产品精修

- 新增「产品精修」节点，可设置背景、布光、阴影和质感。导入原图后自动分析图片并生成可复制的精修提示词；优化了 Gemini 的局部去瑕指令。
- 在画布中直接拖动分界线对照原图与精修结果，可用滚轮放大检查细节。放大时依然可以调整对照分界线，原图与该次精修结果保持配对。

### Agent 与 Canvas MCP

- 多选图片后，可以让 Agent 用同一提示词逐张处理。明确要求运行时，Agent 保存画布后直接启动新批次；各张图片独立生成和预览，单张失败时其他分支继续运行。
- 生图参数按已配置模型的能力选择。Canvas MCP 支持查询可用模型、供应商和参数，并使用与内置 Agent 相同的构图与运行规则。
- 内置 Agent 和 Canvas MCP 可以新建空白工作流、读取历史图片并添加备注，以及查询或保存提示词。新建时保留原工作流；历史备注不改动原图或原提示词；提示词库内容在重启后仍可读取。

### 画布与历史

- 媒体节点从右下角缩放时保持比例，斜向拖动不再突然跳变。空白生图卡片首次拖动即可缩到手动尺寸下限。
- 图片合并面板更清楚地显示来源槽位、合并顺序和输出状态，可直接调整顺序。优化拖线命中和画布节点的连线光标。
- 修复历史操作进度弹窗的配色和居中，历史图片预览支持直接编辑备注。

## 💡 升级说明

无需迁移数据。关闭旧版并更新程序后重新启动即可。已配置外部 Canvas MCP 客户端的用户，可在 CainFlow 的 Canvas MCP 设置中重新生成连接配置，再重启客户端以加载新增工具。
