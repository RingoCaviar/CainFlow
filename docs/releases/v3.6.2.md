## 🚀 3.6.2 更新内容

### 🛡️ 媒体所有权可靠性
- 🔒 建立统一的 Media asset ownership transition contract，固定幂等、冲突、epoch 和恢复结果。
- ♻️ 将 legacy media migration 的 owner promotion 与 temporary owner release 收拢到统一 transition seam。
- 💾 增加跨重启 transition record 重放与 backend storage route，保留 persistent ownership 与 runtime protection 的独立 lifetime。

### ✅ 验证
- 🧪 补充 immutable transition intent、owner 类型隔离、跨重启幂等和 legacy migration 回归覆盖。

## 💡 升级说明

关闭旧版后启动新版，无需手动迁移。升级前建议备份工作流与 `data` 目录；已有未完成的 Media asset transition 会由 backend transition record 自动恢复。
