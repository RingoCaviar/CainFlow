## 🚀 4.1.4 更新内容

### Canvas MCP

- 客户端连接时会收到图片导入指引。历史图片可直接导入，已有画布图片可直接连线。获得文件和界面访问权限的客户端可通过编辑器批量导入其他本地图片，确认素材保存后继续处理。
- 工具说明补充了素材键的读取与引用方式，以及如何通过导入结果找到每张历史图片对应的节点。导入确实受阻时，客户端只需请用户补齐缺少的一步。
- 修复批量导入或应用画布方案后，已取消的会话保存仍被判定为待处理的问题。

## 💡 升级说明

更新 CainFlow 后重新启动，无需迁移。桌面版用户在「画布 MCP」设置中重新复制客户端配置，以更新 MCP 适配器，然后重载客户端。使用源码配置的客户端重载即可。
