## 🚀 3.6.1 更新内容

### 🛠️ 稳定性
- 🖥️ 修复桌面 WebView API 延迟注入时的启动等待与超时处理。
- ✅ 增加桌面桥接就绪状态回归测试，避免启动永久挂起。

### ⚡ 性能
- 🔗 使用 revision 缓存连接 lane 布局，减少重复签名计算。
- 📌 缓存端口顺序查询，减少连接排序中的 DOM 扫描。
- 🧩 复用连接路径参数对象，降低渲染过程中的短生命周期分配。

## 💡 升级说明

关闭旧版后启动新版，无需迁移。建议先备份工作流与 data 目录。
