## 🚀 4.0.8 更新内容

### 画布与连线

- 拖线接近目标端口时会提示实际接入用途，遇到不兼容的目标会显示原因。聚焦端口后按 Enter，也可以用键盘选择目标和用途。
- 添加节点、右键搜索、Alt+N 和拖线到画布空白处共用节点选择器。拖线打开时只显示可接入的节点，创建和连线可一起撤销。
- 点击线身或贴近线身的空白处，可查看连线两端和接入用途。也可从节点右键菜单追踪多级上游或下游，按 Esc 或点空白退出。
- Agent 打开时，画布导航会在选中节点后重新避让。中小窗口用紧凑图标保持导航在同一行。
- 降低了大画布缩放结束时的布局开销。平移画布时，参数浮层会复用已有尺寸并跟随节点。

### 节点反馈与运行范围

- 图片节点卡片可显示本轮等待、运行、实际进度、部分完成或失败。点击状态可查看执行明细。
- 空导入节点提供选文件或填链接的入口。空生图节点会引导配置模型或填写提示词，预览节点会区分未连线、等待上游出图和上游已停用。
- 选中节点后可预览运行范围。单选时可在「仅此节点」「运行到此节点」和「运行整个工作流」之间选择，并查看将运行的节点和可复用的上游输出。

### 电商套图

- 在画布上运行前会检查方案是否已规划、确认且仍有效。发现阻塞时会提示进入对应节点参数，避免提前发起上游生成请求。
- 运行预览会提示本轮图位数、需要生成的图位数和沿用原图的数量。
- 支持独立补跑或停止单个图位。部分完成时，可以一次补齐未完成的图位并保留已完成图片，也可明确选择重做整套。

### 主题

- 切换主题时，协议参数输入框会即时更新文字与背景颜色，保持可读性。

## 💡 升级说明

无需迁移数据或额外配置。关闭旧版并更新程序后重新启动即可。
