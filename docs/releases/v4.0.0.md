## 🚀 4.0.0 更新内容

### 电商套图与生图

- 新增电商套图节点。连接商品参考图后，可按平台选择需要的主副图和详情图，分别设置比例。节点提取商品卖点并规划画面和文案，确认方案后开始生成。
- 套图逐张显示进度和预览，支持单独重新规划或生成。其他图片生成期间也可以排队重试。点击「生成失败」查看原因，重生成失败时保留上一张成功的图。
- 普通图片生成批次也支持逐张查看进度、失败详情和重试。

### 画布与图片预览

- 图片生成、电商套图、文本对话和视频生成共用参考图控件，支持预览原图、按来源排序和断开。视角控制支持预览和替换单张参考图。
- 运行中的节点可以拖动，移动后保留位置。全屏多图预览将缩略图移到底部，压暗周围背景，并提高预览按钮在浅色图片上的对比度。
- 修复图片生成完成时结果操作栏可能与参数面板重叠的问题。

### Agent 与模型

- 明确的新创作请求直接进入方案流程，需要澄清时可提供选项。方案卡片把运行和应用操作移到顶部。
- 默认开启「不压缩上下文」。超过阈值时从最早的对话开始减少发送给模型的内容，完整聊天记录仍可查看。关闭开关后可配置压缩模型和供应商。
- 修复 OpenAI 对话模型的推理参数和生图模型的尺寸、画质及参考图设置。

### 本机 MCP 与执行日志

- 可在「设置 → 常规设置 → 外观与画布 → 画布 MCP」启停服务并复制客户端配置。本机 MCP 客户端可读取、编辑和运行当前画布，并读取结果。
- 执行日志记录套图规划、生成和重试请求，按状态区分颜色，并支持只看失败记录。

## 💡 升级说明

无需迁移数据。关闭旧版并更新程序后重新启动即可。首次使用画布 MCP 时，按设置中的指引为本机客户端安装依赖。
