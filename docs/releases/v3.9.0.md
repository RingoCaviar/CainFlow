## 🚀 3.9.0 更新内容

### 🖼️ OpenAI 多参考图生成

- 修复使用 OpenAI 兼容协议调用 OpenAI 官方图片编辑接口时，多张参考图的上传格式不符合接口约定的问题。
- 多张参考图按图片数组上传，保留完整图片内容及原有顺序；串行、并发批量生成和创作助手使用同一修复。
- 保留单张参考图、遮罩编辑和无参考图生图的原有请求方式。

## 💡 升级说明

无需手动迁移，现有工作流和模型配置可继续使用。升级前保存当前工作流，更新后重新启动应用；此前多参考图生成失败的节点可重新运行。
