## 🚀 3.8.3 更新内容

### 💬 Agent 操作体验

- 优化 Agent 设置面板、模型选择与联网开关的布局和主题适配，明确请求进行中的状态反馈。
- 修复搜图缩略图失效时图片缺失的问题，并改善加入参考图和导入失败时的提示位置。
- 完善参考图、画布方案和节点放置：旧方案提示重新生成入口，新建生图节点避开已有节点并靠近当前视野。
- 增加自动压缩设置，并改进压缩所用模型的选择与显示。

### 🎛️ 画布与工具栏

- 重新整理顶部工具栏分组及按钮样式，适配不同主题。
- 修复恢复工作流后图片生成节点高度异常膨胀的问题。
- 提升深色主题下协议参数编辑字段的文字可读性。
