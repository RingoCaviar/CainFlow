## 🚀 3.6.0 更新内容

### ✨ 体验优化
- 🖼️ 精简图片生成节点布局，保留高级参数。
- 🔍 新增节点搜索、最近使用、缩放导航及提示词库搜索。
- ⚡ 减少画布拖动、连线吸附和节点投影的重复开销。
