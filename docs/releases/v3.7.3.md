## 🚀 3.7.3 更新内容

### 🖼️ Agent 最新生成结果续改
- 修复继续编辑成品时误用旧导入图片的问题：默认使用最新已完成批次，最新批次只有一张时直接绑定，多张且指代不明确时询问修改哪张。
- 最新生成原图进入对话模型请求，保留批次身份和图片序号；相同图片去重后仍保留最新结果身份，同批不同序号不会混淆。
- 生成完成顺序随会话保存，旧方案重试、压缩归档和恢复后仍能识别最新结果，重试保存不会改变顺序。
- 明确指定旧图、其他素材或仅修改提示词时，保留用户意图；已形成的方案不会因后来生成新图而自动更换目标。
- 最新原图缺失或读取失败时提示错误，不回退到旧图或缩略图；切换工作流、清空或取消后丢弃晚到的图片读取结果。

## 💡 升级说明

无需手动迁移，直接升级即可。旧会话没有完成顺序时按已有消息和批次顺序兼容恢复。继续保留手动选择生图模型、先看方案再生成的流程。
