## 🚀 4.0.4 更新内容

### 画布批量连线

- 在画布上多选节点后，从其中一个输出端口拖线，可以把兼容的选中来源一次连到目标输入。也可通过右键菜单进入批量连线模式，查看可用来源数，再点击目标节点连线。
- 拖线时会为各个可用来源显示预览线，吸附目标后只显示能新增的连线。批量新增的连线可一次撤销，拖线过程中可按 Esc 取消。
- 输入和输出端口向节点两侧外移，让端口与节点边框更容易区分。

### 全屏历史

- 标题旁统一显示「共 N 条记录」，移除重复的数字徽标。空目录显示「共 0 条记录」。

## 💡 升级说明

无需迁移数据。关闭旧版并更新程序后重新启动即可。
