## 🚀 3.7.0 更新内容

### 📎 Agent 参考图真正参与生成
- 应用或生成方案时，自动将方案参考图按顺序连接到生成节点；重复应用和重试复用连接。
- 方案清单更新时同步图片输入，保留其他输入端口。来源缺失、禁用、变化或正在运行时明确提示，不静默改为无图生成。

### 🔄 参考图删除同步
- 在画布删除参考图节点，同步移除 Agent 待发送、消息及方案中的对应引用。
- 在 Agent 移除引用仍保留画布节点；已生成的结果图片继续保留。
- 防止晚到的图片导入和模型回复重新添加已删除引用。

### 🖼️ 生成结果拖拽
- Agent 生成图片支持拖入对话框，自动创建图片导入节点并加入参考图。
- 支持拖到画布，在落点创建图片导入节点；使用原图，恢复后的生成结果同样可拖拽。
- 保留点击和键盘预览，避免拖拽误触预览及重复导入。

### 🔢 版本号规则
- 固定采用逢十进一规则，次版本和修订号范围为 0 至 9；本版从历史版本 v3.6.10 递进到 v3.7.0。

## 💡 升级说明

无需手动迁移，直接升级即可。旧方案缺少参考图清单时保留节点现有输入；参考图来源已删除或失效的旧方案，请重新选择参考图。生图模型仍由用户手动设置。
