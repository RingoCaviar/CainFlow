## 🚀 4.1.2 更新内容

### 电商套图

- 详情长图可一次规划整页的配色、字体层级、阅读顺序和各屏之间的衔接。生图模型按图位直接生成带文案和排版的成图。
- 可连续预览详情图，用自然语言调整整页或单屏版式，也可在图位中编辑多行文案。重新生成前仍可预览上一版图片。
- 「套图输出」按阅读顺序传递详情成图。「导出套图」可单独打包详情图原图。
- 内置 Agent 和 Canvas MCP 可读取详情图的总屏数和就绪屏数。

### 画布

- 提示词插入的上游图片引用采用参考图列表中的编号。重新排序参考图后，已有引用仍指向原来选中的图片。
- 修复点击「生成」时参数浮层移动，导致鼠标松开后未触发生图的问题。

## 💡 升级说明

关闭旧版并更新程序后重新启动，无需手动迁移。旧工作流中的详情成图仍可查看。要为已有图位应用新的整页设计，请重新规划并生成相应图位。
