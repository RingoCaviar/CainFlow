## 🚀 4.1.7 更新内容

### 画布交互

- 修复中键开始平移时整个节点层被临时提升、需要额外重绘的问题。首次拖动即可平滑跟随指针，节点、网格和连线保持对齐，松手后平移状态正常结束。

### Canvas MCP

- 凭据缺失或跨域请求被拒绝时，Canvas MCP 会稳定返回明确的 403 响应，不再偶发因连接重置而只看到传输错误。
