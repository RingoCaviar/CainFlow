## 🚀 3.7.1 更新内容

### ⌨️ Agent 输入快捷键
- 支持 Enter 发送消息、Shift+Enter 换行。
- 中文输入法确认选词不会误发送，长按回车不会重复提交；保留命令菜单的键盘操作。

### 💾 会话保存修复
- 修复会话与设置并行保存时，累计请求超过浏览器 keepalive 配额导致的保存失败；配额不足时使用普通请求重试。
- Agent 单独确认会话文档是否保存成功，避免其他设置保存失败时误报“生成完成，但保存失败”。
- 保存批次等待全部请求结束后再重试失败文档，减少旧请求覆盖新数据的风险。
- 真实会话写入失败仍保留图片保护和保存重试，并显示具体错误原因。

## 💡 升级说明

无需手动迁移，直接升级即可。已有生成结果若仍显示保存失败，可点击“重试保存”，无需重新生成。本次不改变 Agent 方案的参考图选择规则。
