## 🚀 3.9.3 更新内容

### 图片预览与历史记录

- 节点、Agent 和历史图片预览均支持保存原图，保留原始格式；桌面端和支持的浏览器可选择保存位置与文件名。
- 修复历史记录多选切换和窄栏操作布局，改善下载失败提示。
- 修复媒体保存时的标识冲突，避免不同图片错误关联。

### 界面与更新

- 统一确认与输入弹窗，改善操作体验。
- 支持更新完成后安全重启桌面应用。
- 移除仓库附带的 Default 工作流文件。

## 💡 升级说明

无需数据迁移，已有工作流与参数保持兼容。关闭旧版并更新程序后重新启动即可。本次按维护者要求执行快速测试与发布文件校验，未执行全量回归。
