## 🚀 4.1.3 更新内容

### 电商套图

- 已有方案时，商品参考图和设置可收进「套图配置」，优先展示图位、缩略图和可执行操作。详情长图缩略图随面板宽度调整，保留完整比例。
- 套图方案显示已完成、待补齐和上一版图位。生成时显示完成、失败、运行和取消数量，底栏分开显示补齐和重做的范围及调用量。
- 套图齐备后可直接导出，也能导出部分成图或上一次套图。ZIP 打包在后台执行，桌面端保存大包时界面仍可操作。
- 修复短窗口中套图操作被裁切的问题，并减少更新图位时的界面卡顿。

### 画布与节点

- 重新组织生图浮层、视频生成、智能对话、产品精修和视觉风格的参数区。窄面板可按可用宽度换行，保留滚动正文和操作按钮。
- 视频生成显示任务与结果，待恢复的任务出现时自动展开恢复区。智能对话的搜索和复用开关可就地调整，复制和查看操作紧邻回复。
- 改善触屏拖动和画布参数面板的交互。

### Agent 对话

- 长对话首次打开时显示最近 60 条消息，可向上加载更早的记录。切换工作流时按需渲染对话，计算上下文用量时才加载相关模块。
