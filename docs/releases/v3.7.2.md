## 🚀 3.7.2 更新内容

### 🖼️ Agent 上下文参考图
- Agent 可结合画布素材、历史附件和生成批次理解编辑对象，未手动附图时也能提出对应素材的方案；目标不明确时询问用户。
- 精确定位多图结果中的单张图片，生成结果通过独立图片导入节点接入方案，避免自连接或误用整批图片。
- 素材缺失、删除或切换工作流时阻止过期导入，保留先看方案、手动选择生图模型再执行的流程。

### 🧠 Token 阈值自动压缩
- 按 Token 阈值调用对话模型压缩上下文，不再简单截断历史文本；保留历史记录、参考图和最新完整方案。
- `/compact` 菜单用圆环显示达到自动压缩阈值的进度，对话模型可设置阈值，默认 12000 Token。
- 文本改用离线 BPE 分词，已知图片模型按尺寸和规则估算，并用接口返回的实际输入用量校准；未确认的模型和图片规则明确标注估算。
- 压缩失败时保留原上下文；取消、清空和切换工作流不会接纳晚到结果，压缩期间新输入的草稿及附件也会保留。

## 💡 升级说明

无需手动迁移，直接升级即可。上下文圆环表示自动压缩阈值进度，不是模型总容量或累计消费；部分供应商仍使用估算计数。自动压缩会调用已配置的对话模型，按该供应商规则产生用量。
