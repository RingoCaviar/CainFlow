## 🚀 3.5.8 更新内容

### 🖼️ 图片剪贴板
- 修复 Windows 桌面版中从节点图片右键菜单或全屏预览右键菜单复制图片后，无法粘贴到其他软件的问题。
- 桌面版现在将图片像素写入 Windows 系统剪贴板，并保留到应用进程退出后；复制失败时显示错误提示。
