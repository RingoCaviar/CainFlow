## 🚀 3.7.8 更新内容

### 🎨 七套主题配色修复

- 修复 Agent 节点提及菜单背景透明、选中与键盘焦点不清晰的问题，统一模型、参考图菜单和消息的语义配色。
- 修复浅色主题下协议编辑器仍使用深色面板与输入框的问题，改善参数、请求预览及保存状态的可读性。
- 限定协议按钮颜色的作用范围，避免影响其他面板。

### 👁️ 提升文字与操作辨识度

- 改善历史、缓存、统计和日志中部分说明及空状态文字的对比度。
- 修复 Paper 主题更新通知取消按钮颜色过浅的问题，统一普通、悬停和焦点状态。
- 运行及主操作按钮使用配套的主题填充与文字色，修复部分亮色渐变上的白字不清晰，保留原有尺寸、边框及阴影。
- 扩展七主题真实浏览器回归，覆盖窄面板菜单和图片预览。
