## 🚀 4.2.0 更新内容

### 画布文件导入

- Windows 桌面版支持把本地文件拖入画布，创建引用原件的文件导入节点。TXT 和 Markdown 可直接预览并连到智能对话，图片和视频可传给兼容的下游节点。PDF 和 Office 文件可用系统默认应用打开。
- 工作流再次运行时会读取原件的最新内容。文件移动或改名后，可在原节点重新定位。更换文件类型时会提示受影响的连线，确认后可以撤销整个更换操作。
- 导出的工作流只携带文件名和类型等定位信息。接收方可以在原节点选取自己的本地文件，恢复兼容连线。

### 画布节点尺寸

- 修复重启应用后节点尺寸变化的问题。重新打开工作流时会恢复手动调整过的卡片尺寸，智能对话的长回复可在卡片内滚动。
- 改进节点边缘拖拽，放大的卡片可缩回内容允许的最小尺寸，快速松开鼠标时按最终位置完成调整。

### 节点参数

- 智能对话把提问框放在首位，并在缺少问题或模型配置时给出操作提示。底栏可分别打开「模型与供应商」和「回答设置」，窄窗口中仍可访问生成按钮。
- 生图参数浮层默认宽 480px。参考图达到八张时，空间允许便扩到 560px，方便点击和拖动缩略图。手动调整过的宽度优先，窄窗口中可横向滚动缩略图条。
- 视频生成卡片显示当前模型，展开「模型与供应商」即可修改。同步调整了参数浮层的控件对齐。
