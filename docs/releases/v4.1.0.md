## 🚀 4.1.0 更新内容

### 画面风格与电商套图

- 新增「画面风格」节点。可从八类共六十种预设中选择并编辑风格描述，或连接参考图并按五档精细度提取风格。风格输出可复用于生图和电商套图。
- 电商套图按连接的画面风格生成。自定义场景折叠时也可以生成方案和确认生图，候选图可预览、采用和追加生成。

### 画布与工作流

- 优化拖动、平移、缩放和首次选中节点时的响应。设置中新增默认开启的「画布 GPU 加速」开关，遇到显示异常时可关闭。
- 右下角「运行范围」统一提供运行入口，可在确认前查看执行范围。未选中节点时也能运行整个工作流。运行期间顶栏显示状态和停止按钮。
- 可用画布右键菜单、Alt+N 或拖线到空白处添加节点。空画布保留「添加第一个节点」入口。
- 修正更新下载进度条在已知和未知下载大小时的显示。

### 模型设置

- 为云雾等兼容网关补充 OpenAI 模型目录，并继续读取 Gemini 后续页。列表按模型 ID 去重，部分分页失败时保留已读结果。

### 内置 Agent 与 Canvas MCP

- 内置 Agent 按需查看画布原图时，会分别报告无效引用、图片缺失、读取失败或模型不支持图片输入，并继续处理可读的图片。
- Canvas MCP 支持按同一画布版本读取后续页面，避免把不同版本的内容拼在一起。运行结果可按节点分页，并提供错误摘要和结果省略提示。

## 💡 升级说明

关闭旧版并更新程序后重新启动，无需手动迁移。使用 Canvas MCP 分页读取画布时，建议将首页返回的编辑器、工作流和画布版本传给后续请求。
