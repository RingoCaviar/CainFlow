## 🚀 3.8.6 更新内容

### ⚙️ Agent 设置与输入

- 选择 Agent 上下文压缩模型时，模型列表和已选值会显示关联供应商，便于区分同名模型。
- Agent 输入框两侧的添加参考图和发送或停止按钮与输入框垂直居中。
- 输入框高度可通过右上角的拖柄调整，拖柄也支持键盘方向键。

### 🖼️ 图片预览

- 从节点、Agent 图片或历史记录打开图片预览时，右下角提供放大、缩小和适应屏幕按钮。
- 预览右上角的操作按钮默认折叠；鼠标靠近或键盘聚焦时会展开，并带有展开动画。在触屏设备上也可点击“预览操作”按钮展开。

## 💡 升级说明
