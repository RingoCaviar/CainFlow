## 🚀 3.6.4 更新内容

### 🐛 图片导入运行一致性
- 🖼️ 修复替换图片后立即运行工作流仍读取上一次图片的问题。
- ⏳ 工作流创建运行快照前会等待当前图片导入完成，避免异步持久化与执行产生竞态。
- 🔒 连续快速导入多张图片时仅最新一次结果更新节点，同时完整等待并清理较早写入。
- 🔗 统一图片导入节点在序列化、运行时恢复和节点克隆时的 Media asset reference list 优先级。

## 💡 升级说明

关闭旧版后启动新版，无需手动迁移。已有工作流和图片导入节点会继续使用当前持久化的 Media asset reference list。
